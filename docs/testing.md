# 实现验证边界

首票沿已确认规格的 Testing Decisions 与工单验收项，使用任务 API 的可观察行为作为测试边界：原生 thread／run 发起、重送、查询、流式、取消，以及受控当前内容读取。测试不依赖图节点名称或内部函数调用次数。

只有 API 难以定位的知识语义、输入隔离和有限数学计算增加小范围测试。可控模型与知识服务仅在测试配置中注入；正式入口使用真实 Gemini 与本地 browse。真实生成另留证据，不能被固定模型测试代替。
