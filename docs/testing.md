# 实现验证边界

首票沿已确认规格的 Testing Decisions 与工单验收项，使用任务 API 的可观察行为作为测试边界：原生 thread／run 发起、重送、查询、流式、取消，以及受控当前内容读取。测试不依赖图节点名称或内部函数调用次数。

只有 API 难以定位的知识语义、输入隔离和有限数学计算增加小范围测试。可控模型与知识服务仅在测试配置中注入；正式入口使用真实 Gemini 与本地 browse。真实生成另留证据，不能被固定模型测试代替。

本次实现前基点：`d60992956d48a1e0faae4b5037bbd3ee2da5bb1e`。完成后按此基点执行规范／规格两轴代码审查。

真实模型暴露的适配失败另在供应商工具转换边界固定：六项检查依据必须在 Gemini 接收的 Schema 中仍然存在。取消后快速重启的框架重放以已有真实执行证据复现到 API，验证累计消耗不归零且不产生新模型调用；该测试不宣称框架本身已具备完整取消持久性。

详细实测、两轴审查与覆盖局限见 [首票验证报告](../.scratch/math-harness-delivery/evidence/01-live-curriculum/README.md)。

全年扩展从 `7abdd2b` 开始：增加年级层级和分页的真实 HTTP 边界、全年输入范围、内容保存／渲染、同一阶段图的覆盖阻断、原生任务与单元交接以及 Gemini Schema 转换验证。用服务当次返回的动态数量核对完整性，不固定旧快照节点数。合成模型即使返回空 findings，程序也不能放过目标遗漏。真实全年生成和教学审阅另存证据，不把合成测试的“通过”用作内容质量结论。

本轮完整测试 83 项通过，之后真实阅读稿暴露表头未加公式标记的 LaTeX，增加先红后绿回归，受影响内容测试 14 项通过。双轴审查另补交接实际图件、必要标准祖先、知识失败分类、CLI 请求与来源组合；实际结果及未完成的浏览器视觉验收见 [全年验证报告](../.scratch/math-harness-delivery/evidence/15-full-year-blueprint/README.md)。

年级课程评价与检查校准（23）从 `e28c3d3` 开始，测试放在事先确认的六个边界：评价记录契约及其导出、证据按原文位置与指纹回取、独立评分的汇总与比较、逐对象程序检查、校准样本与输入隔离，以及模型评阅、裁定与修订的适配。模型边界用脚本模型验证伪造引用、缺反例、漏交维度和答案泄漏的处理；专项检查（承诺、探查、数学表述）与评价用模型的适配同属这一边界，测试程序对抽取结果的判定、独立求解的输入隔离、逐项回应的补交、严重度上限、重复运行的共识、失败调用的记录，以及输出被截断时按失败处理、实际输出上限与记录一致。本地命令只测补跑的选择与合并（整体评阅的 `still_failed`、`combine_retry`，专项检查的 `stage_action`），其余命令行为靠真实运行的记录核对。真实 Gemini 只用于校准证据，不作为单元测试。有效样例取自 15 终稿原文，注入问题与合法对照以 15 终稿副本构造。实际运行、检出统计与局限见 [23 证据报告](../.scratch/math-harness-delivery/evidence/23-grade-evaluation/README.md)。
