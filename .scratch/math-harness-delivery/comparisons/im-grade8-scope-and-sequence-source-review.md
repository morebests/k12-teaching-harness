核查日期：2026-09-16。

本次对照由用户明确授权。现有生成稿保持冻结；本文件只记录 IM 官方材料的内容结构、教师用途和获取局限，不评价本地生成稿，也未形成 IM 与本项目的学习效果比较。采用项目既有读取路由，已读 README、领域说明、资料索引及课程体系能力资料。

## 1. 用户给出的页面是什么

[Grade 8 Scope and Sequence](https://accessim.org/6-8/grade-8/course-guide/scope-and-sequence?a=teacher) 是 IM v.360 八年级的全年进程入口：它连接九个单元、单元内的 Section 与 Lesson，并解释全年数学工作如何衔接，配有节奏建议和先修依赖图。第九单元为可选的综合应用。

全年叙述从变换、全等和相似建立几何基础，接到斜率与线性关系，再发展方程、函数和数据；后续还有指数、科学记数法、勾股定理及无理数。这些说明让教师判断一块内容为何在这里、承接什么、准备什么，而不仅是知道题目名称。页面的编号顺序与依赖图承担不同职责：依赖箭头表示这套课程设计中的前置关系，不能把所有相邻编号都理解成硬性先修。以上是该页面的组织方式，不是要求其他课程采用相同单元拆分。

## 3. U2 → U3 → U4 / U5：再访已有内容时新增什么

| 官方单元 | 新增的数学工作 | 如何承接既有工作 |
| --- | --- | --- |
| [Unit 2：位似、相似与斜率初步](https://accessim.org/6-8/grade-8/unit-2?a=teacher) | 用相似三角形说明同一直线斜率比值不变，把点的坐标关系与直线联系起来。 | Section C 明确暂不要求学生写斜截式；这里主要建立几何依据，为后面的直线结构作准备。 |
| [Unit 3：线性关系](https://accessim.org/6-8/grade-8/unit-3?a=teacher&lang=en) | 从正比例进到变化率固定但不经过原点的关系，解释初值、斜率、截距，扩展斜率与二元方程解的理解。 | 重访比例图的坐标标签、尺度及多种表征，是为了支持后面的非正比例情形。后段包含水平线、竖直线和方程解与图上点的关系。 |
| [Unit 4：线性方程与方程组](https://accessim.org/6-8/grade-8/unit-4?a=teacher) | 建立等价变形的理由，求解一元方程并识别一解、无解、无穷多解；随后研究两个方程同时成立。 | 从等量模型进入符号推理；利用直线上的点理解方程组的解，再从图解走向更精确的代数求解。 |
| [Unit 5：函数与体积](https://accessim.org/6-8/grade-8/unit-5?a=teacher) | 以允许输入对应唯一输出建立函数观念，解释不同表征，研究变化率，并用函数关系考察体积与尺寸变化。 | 已学的比例、线性关系及公式成为函数实例；函数视角是新增工作，正式函数记号留到后续课程。体积部分与这一视角相连。 |

官方[依赖图原图](https://cms-assets.illustrativemathematics.org/qo2pv9vlbcw8aeqowj96zxh6c0tb)在八年级内部显示 8.1 → 8.2 → 8.3，而 **8.3 分别指向 8.4、8.5、8.6**。它没有把 8.3 → 8.4 → 8.5 画成逐项硬依赖。该 SVG 的网页文字工具不支持其内容类型，本次在正常 Chrome 标签页打开原图后，通过截图核读箭头；未下载。

由此可以提出一个结构核查问题：重复出现同一术语时，这一次增加了什么推理、表征或应用责任？这比只按术语是否重复更可靠。它是根据官方安排提出的审阅方法，不是本地稿已经通过或不通过的结论。

## 4. 各层职责：Section 有教学进程，Lesson 承担具体实施

IM 官方的 [What’s in an IM Lesson?](https://accessim.org/6-8/grade-8/course-guide/an-im-lesson?a=teacher&lang=en) 说明多层 Narrative 的作用。结合相应页面，可区分为：

| 层级 | 教师需要理解的事情 |
| --- | --- |
| 全年 / Grade | 全年主要数学工作、单元顺序、先修关系及时间安排。 |
| Unit | 一组数学目标为何放在一起，如何发展并与前后单元连接。 |
| Section | 连续几课共同推进什么工作，每课在这段进程中承担什么。 |
| Lesson | 当天数学目标及其位置，怎样组织任务、观察学生并进行总结。 |
| Activity | 当前任务为何有用，学生具体做什么，教师观察什么并怎样连接想法。 |

Unit 3 将 15 个 Lesson 分成五个 Section。例如，Section B 组织 L5–8 的线性关系表征工作。Section 层有进程叙述、目标和课时导航，也可使用代表情境或图解释进程；不能把“出现任何具体例子”直接认定为越界。[来源：Unit 3 总页](https://accessim.org/6-8/grade-8/unit-3?a=teacher&lang=en)

真实的 [Lesson 5 准备页](https://accessim.org/6-8/grade-8/unit-3/section-b/lesson-5/preparation?a=teacher) 已经下沉到当天的要求：本课研究正变化率的非正比例关系，初步出现截距但暂不要求学生识别；列出方格纸、直尺及标准的承接关系。杯子情境提供照片和测量数据，教师若改用实物则需预先测量并检查数据是否适合这个模型。这些都是实施准备信息。

[Lesson 5 实际课时页](https://accessim.org/6-8/grade-8/unit-3/section-b/lesson-5?a=teacher) 进一步给出 5 分钟热身、两个各 15 分钟的主要活动、具体学生题面、启动方式、分组与讨论、教师观察点、总结及检查入口。例如，杯数只能取整数，教师需要区分整条直线与情境中有意义的点；这是具体任务中需要处理的数学细节。活动中的比较表征、提出问题也对应语言支持。

因此，区分层级要看它解决哪个教学决策，而不是只看字数或是否有题目。官方 Section 解释数课共同的学习进程；Lesson 提供当天可执行的教学安排。

## 5. 语言进程与检查如何服务教师

官方[数学语言发展说明](https://accessim.org/6-8/grade-8/course-guide/math-language-development?a=teacher&lang=en) 将语言发展与数学理解一起设计：不仅列词汇，还关心学生怎样解释、比较、概括和论证。语言目标进入课时目标，活动按表达需要配置语言支持与数学语言常规；支持学生进入数学工作，不等于降低数学要求。

单元语言进程把表达功能对应到具体课，并区分词汇的理解性接触与主动使用；这些安排须与学生当时的数学工作一起阅读。[Unit 3](https://accessim.org/6-8/grade-8/unit-3?a=teacher&lang=en)、[Unit 4](https://accessim.org/6-8/grade-8/unit-4?a=teacher)

官方[评测指导](https://accessim.org/6-8/grade-8/course-guide/assessment-guidance?a=teacher&lang=en)区分课前准备诊断、课末检查、Section checkpoint、单元末评及部分长单元的中期评测。这些证据用于决定后续继续提供机会、调整教学重点，或暂停推进并增加学习。不能机械推断每个 Section 都有独立检查：Unit 3 的末尾整合 Section 紧接单元末评，总页明确不另设 Section goals/checkpoint。

对教师的实际用途可据这些入口概括为：全年页帮助安排节奏与判断先修；单元和 Section 说明帮助理解为何这样推进；Lesson 准备和教学页帮助备材料、组织课堂、观察学生；检查及反馈说明帮助决定下一步。这里只确认材料提供了这些支持，未调查教师是否愿用，也未测量课堂成效。
