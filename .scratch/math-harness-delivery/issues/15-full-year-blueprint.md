## What to build

调用方请求完整全年方案，Harness 取得完整八年级 CCSS 内容及实践范围，设计自有单元组织、Narrative 与学习进程，并交付有覆盖检查的真实全年蓝图。承接首票移出的全年工作。

## Acceptance criteria

- [x] 经同一任务 API 使用实际本地数据遍历全部必要层级和分页；缺页、空集、排除和错误有不同结果，不能硬编码旧快照节点数来证明完整。
- [x] 目标、学习进程、各单元职责与 Narrative、先备／后续和学校时间条件齐备；Learning Components 和图关系实际用于设计，模型推断与图事实分开。
- [x] 全年内容标准和实践标准分别有覆盖依据；单元位置由本设计决定，线性函数不预设为 IM Unit 4。
- [x] 用关键任务构想试查单元职责是否可实施；不要求本票生成全年逐课材料，也不把构想视为已展开课时。
- [x] 检查遗漏、重复、目标与时间矛盾等问题，反馈修订实际方案；严重问题保留并阻止相应通过声明。
- [x] 提供相关线性函数单元的具体版本、目标分配、时间、Narrative 和前后联系，可被课时设计直接读取；不得从临时首票课段暗中补出全年事实。
- [x] 真实运行保存输入、规则、知识、消耗、实际方案与检查；目标 IM 持续隔离，外部调用示例和 OpenAPI 同步实际支持范围。

原勾选项和证据保留为此前有限工程验收；不得用它们证明全年规划质量已达到目标。当前追加工作尚未完成：

- [ ] 将目标依据、全年布局、各单元规划进程和综合核查落实为有效版本的阶段成果及前进条件。
- [ ] 按阶段和具体问题装配 Context，保留全局约束、实际原文回取与失效检查，验证不会依靠无限追加作者历史完成全年。
- [ ] 以旧漏检、新变体和合法对照检查发现／修复能力；反馈带证据与对象，检验修订保真。
- [ ] 运行全年规划与修订，交付当前阅读稿、阶段和调用证据；不以单课或完整单元的结果替代。
- [ ] 按固定规则与同尺度 IM 证据完成逐维比较，明确强弱、重大问题、分歧和不可观察项；修订弱项后复评。

### 2026-09-16：对照结论的重心与证据更正

上一条对照过度突出 Unit 2／3。现有文字只支持进一步核对学习职责，不足以判定其单元安排错误；它不构成整个后续工作的通用前置。应从[对照报告中的可吸收方法](../comparisons/im-grade8-blueprint-comparison.md)改进全年数学联系、分层 Narrative、学习与表征进程、语言发展、练习评价及教师使用方式，并在实际生成和审阅中验证。早期文档与运行规则已有部分要求，我在实现和验收中没有充分兑现，不能把这些原则写进报告后就声称问题解决。

### 2026-09-16：完成后与 IM 全年指南对照

按用户要求完成[固定全年稿的内容对照](../comparisons/im-grade8-blueprint-comparison.md)。已确认单元内部课段／课时职责尚未展开、Unit 2 已教 `y=mx+b` 与 Unit 3 初期突破正比例的界限不充分，以及全年阅读稿直接展开完整题解等问题。保留本票工程及有限蓝图完成事实与原始检查；这些新发现没有被原 `checks.json` 的通过结论消除，也尚未修订产物。03 使用实际父级时先澄清目标课相关职责，17 落实正式课段；不以单元顺序不同于 IM 判为错误，不以一次内容审查宣称教学效果或完整质量通过。

### 2026-09-16：完成全年实现与三轮真实检查修订

沿同一阶段图增加 `scope=year`、完整年级投影遍历、全年内容及覆盖检查、阅读稿与带指纹的实际单元交接。当前方案为 8 单元、160＋20 课时，33 叶目标与 3 父目标、八项实践分别分配职责；线性函数位于本设计第 3 单元。双轴代码审查各 2 项问题均修复，完整测试 83 项通过，后续格式回归的受影响测试 14 项通过。

初稿模型检查漏查资源和统计问题，人工反馈后继续修订；末轮统一数据范围、合成来源、截距解释及公式标记，程序反馈还驱动了实际知识补查。[验证报告](../evidence/15-full-year-blueprint/README.md) 保存三轮全部消耗、真实输入、规则、工具请求／返回、内容和检查；[实际单元包](../evidence/15-full-year-blueprint/final/unit-handoff.json) 已由公开 API 读取验证。浏览器预览受工具策略限制，本轮未完成视觉验收；全年蓝图不代表完整 Lesson、教师校准、课堂或生产保证。

下一内容票为 03，以本票实际单元展开一课及师生材料，再由 17 承接正式课段和连续三课。原 triage 角色不因实施完成改名。
