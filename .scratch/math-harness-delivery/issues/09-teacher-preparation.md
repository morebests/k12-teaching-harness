# 围绕真实任务完成教师参与的备课

Status: ready-for-agent
Blocked by: [让真实教学决定跨进程等待并恢复执行](02-human-decision-and-resume.md)

Size: M/L — 一个真实原课的任务讨论与便签；主要风险在信息顺序和教师贡献语义。

## What to build

教师提供真实课时，Harness 先试做并识别一个具体教学难点，通过短而有内容的互动取得教师自己的分析，形成与该课有关、可使用的备课便签。参与动作本身是教学工作的一部分。

## Acceptance criteria

- [ ] 使用首条课程任务已提供的实际内容引用读取原课；可来自本 Harness 或调用方规范化的授权外部文本／结构内容。教师便签用通用内容写入，不依赖师生排版器。无法取得实际任务时不编造亲做或学生表现。
- [ ] 运行资源覆盖原 prep 的完整流程和 rubric，形成逐条取用及判据；模型实际试做目标任务，尊重原课方法与组织，不擅自重编课程。
- [ ] 正常路径先呈现原任务，请教师产生或分析 near-miss；教师贡献前不泄露系统预拟的 near-miss 或全部解答。near-miss 的关键缺口在推理或条件，不是数值接近。
- [ ] 保存教师原始贡献、对象版本及实际后续影响；反馈有据纠正数学错误，最终便签体现真实贡献，不套用一份预写总结。
- [ ] 先问概念时先解释必要内容，不自动替教师完成全部 near-miss；明确要求模型示范、拒答、很短准备时间和结束遵守各自例外，记录未发生的参与。通用任务取消由取消票提供，最终集成复验，不重复建设。
- [ ] 不制造每一步审批或长菜单；只作必要的有针对性追问，教师能够按明确意图结束。计时约束来自教师需要，不能由模型调用预算替代。
- [ ] 便签按实际课时教学顺序提供具体难点、学生思路和应对，遵守原流程对精简可用笔记的要求；如果教师明确不要便签，记录例外而不强制输出。
- [ ] 通过任务 API 验证正常贡献与关键例外、持久等待／恢复、信息泄露和贡献未被采纳的反例；真实教师互动与合成测试严格区分。
- [ ] 质量报告核对方法准确、难点具体、数学正确和实际参与影响，不能用对话轮数或存在便签判为备课通过。

## Reading and boundaries

读 [规格](../spec.md)、[prep 详细分析](../../skills-harness/assets/execution-contract-draft.md)、[prep 原 Skill 与内置 rubric](../../../k12-teacher-skills/plugin/skills/k12-lesson-prep/SKILL.md)、[HITL 设计](../../skills-harness/assets/hitl-design.md)。

复用实际内容读取与任务持久交互，不依赖教案生成、学生页渲染、适配或完整单元完成。任意上传文档解析不是备课隐含前置；首批接收规范化原课。未经授权不联系外部教师；真实参与验证在可用参与者和范围内开展，未发生就保留待验证。

## Comments

### 2026-09-15：移除生成器依赖

源码要求真实原课，不要求由本仓库先生成。原依赖把输入可用性误作功能生成依赖；当前以首票的内容契约和回应票为基础。技术上可提前，不意味着排程上抢占全年到课时的主线。
