# 在持久部署中重启和恢复实际教学任务

Status: needs-triage
Blocked by: [在崩溃和调度结果不明后自动恢复任务](18-crash-reconciliation.md)

Size: L — 一个冻结版本的持久环境与备份恢复；身份撤销和跨版本兼容另行验收。

## Ready condition

已有实际运行包后，确定用于本票测试的部署版本、可用许可与目标持久环境、业务库和产物存储配置。可先选择有授权的本地部署候选，不要求先有正式学校宿主；环境不可用时保持待落实，不能用配置文件替代实测。条件明确后收口成一次部署／恢复试验，再转为 `ready-for-agent`。

## What to build

将可运行的教学任务部署到采用持久数据库和产物存储的 Standalone Agent Server 候选环境，实际重启、备份和恢复任务。身份／撤权一致性由 [访问控制](21-access-revocation.md) 负责，跨版本等待由 [版本升级](22-waiting-task-upgrade.md) 负责。生产能力由目标环境实测证明，配置文件或 dev 重启不能代替。

## Acceptance criteria

- [ ] 冻结并核对实际框架版本及许可条件；记录 PostgreSQL／Redis、业务记录、checkpoint 与产物存储的职责和配置，不将运行镜像或 Key 写进源码。
- [ ] 提供可重复部署、健康检查、启动／停止、备份／恢复和故障诊断入口，实例数量与非 scale-to-zero 条件按实际采用版本处理。
- [ ] 验收程序经同一任务 API 执行真实内容的创建、待答、回应、重送、取消、续作和材料读取，不建立绕开业务入口的“验收特权路径”。
- [ ] 实际 worker 硬退出、数据库／产物分离故障、调度结果不明和流断连的测试可重跑；已具备条件的持久环境实际运行并保存结果。
- [ ] 已实现的可信身份和内容访问检查在部署环境保持生效；环境配置不绕过基本隔离。权限撤销的深入测试由访问控制票完成，不能将基本授权延后到那张票。
- [ ] 用同一冻结版本完成实际备份／恢复，内容引用、检查与待答对象均可读；不声称已完成跨版本迁移。并发公共基线条件采纳的业务行为由跨层修订票负责，正式部署验证复用其用例。
- [ ] 提供负载测试入口并记录实测条件，区分模型活动和人类等待；未给目标工作量时不捏造容量数字或 SLA。
- [ ] 实际部署与恢复证据是本票完成条件；如果只交付了包和验收入口，本票保持未完成。目标学校宿主的后续复验另记发布门槛，不将候选环境成绩冒充正式环境结果。

## Reading and boundaries

读 [规格](../spec.md)、[主执行设计](../../skills-harness/assets/main-execution-design.md)、[完整运行研究](../../skills-harness/issues/11-agent-server-stack-research.md)、[Agent Server 研究](../../skills-harness/assets/langgraph-agent-server-research.md) 和 [生产验证路线](../../skills-harness/assets/validation-and-release-route.md)。实施时重新核对所选版本的官方事实。

本票可在真实课程任务和恢复基础具备后推进，不依赖所有教学能力完成。部署包及验收入口由本仓库交付；目标环境和身份／许可等外部条件在正式部署前落实。不得自动购买服务或把缺失环境写成成功。
