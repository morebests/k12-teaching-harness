# 按自然语言修改课程并重查受影响内容

Status: ready-for-agent
Blocked by: [从全年蓝图交接到连续三课](17-curriculum-lesson-handoff.md)、[取消教学任务并续作明确停止的工作](05-stop-cancel-and-recovery.md)

Size: L — 一次有范围的跨层修订及局部支持对照；不能把影响分析、修改和复查分别交付。

## What to build

课程负责人提出压缩课时等自然语言修改，Harness 从实际旧版本分析影响，修订课程安排及相关任务、材料、检查；教师提出局部支持变化时保持其个人／班级范围。返回可审查的新旧差异和剩余问题。

## Acceptance criteria

- [ ] 修订接口记录原始意图、基线和目标引用；运行中先使旧提交无效再串行修订，已结束任务建立有来源关系的新任务。
- [ ] 对有实际课时的范围演示一次结构修改；不仅更新标题／课时数，还检查目标、学习机会、材料、时间及前后依赖。可以先在连续三课和父级蓝图上验证，不必等完整单元实现完毕。
- [ ] 保留旧依赖并识别新增依赖，修正相关 Narrative、练习和评测建议；不只遍历修改后仍存在的边。
- [ ] 未展开的课时如实标注推断边界，不声称已经验证其容量；对不能维持的教学目标给出具体冲突，不生成无依据的效果保证。
- [ ] 对比一个只影响班级／个体支持的修改，公共课程基线及无关材料保持有效；持续支持不会因为一般支架撤除规则被取消。
- [ ] 新材料引用、师生视图和检查版本一致；旧检查只有在输入与规则仍有效时复用，变更影响必须重查。
- [ ] 并发任务对同一公共基线的采纳，由外部所有者按预期版本条件完成；本任务工作完成不冒充公共基线已采纳。
- [ ] 自然语言否定、条件修改和已答后的新意图得到正确处理；沿已有授权推进，只有实际超出授权的取舍才待人。
- [ ] 通过 API 验证并发冲突、迟到输出和失效检查，并保存实际模型修订前后内容及质量裁定。

## Comments

### 2026-09-15：按实际交接保留必要依赖

需要的是已有跨课内容关系和旧提交失效能力，因此依赖连续课时交接与主动取消，不必等完整单元、通用硬退出验收或生产部署。
