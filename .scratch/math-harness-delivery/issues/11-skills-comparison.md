# 从课时创建开始建立可离线复现的 Skills 对照

Status: ready-for-agent
Blocked by: [直接生成一课的真实师生材料并检查修订](03-continuous-lessons-and-materials.md)

Size: L — 创建参考执行与独立评价；限定直接完整生成路径，复用全年已有证据记录机制。

## What to build

将已实现的单课直接生成路径与固定原 Skill 放入可重复的同条件对照，尽早检验 Context 和材料生成机制。复用 23／26 已验证的证据记录与报告机制，按创建自身规则交付可离线运行的案例、参考执行、独立评价及实际试运行；若契约不够则按具体差异扩展，不重建全年评价器。其余能力和草稿交互由 [四项对照汇总](19-four-capability-comparison.md) 扩展；LangSmith 可关联结果，但停服不能阻止评价执行。

## Acceptance criteria

- [ ] 固定创建上游源码、实际输入、资源、工具、模型和配置；列出宿主适配改动。原 Skill 必需资源不全时标为未复现，不给弱化基线冒充原效果。
- [ ] 按案例固定双方资料可得范围及参考接触记录，完整满足原 Skill 的必需资源；仅在另设未接触参考的实验时应用对应隔离时点。参考输出与保留评阅答案不进入被测生成 Context，不能弱化基线。
- [ ] 优先同模型及可比资源／工具比较机制；若另做原宿主／模型体验对照，独立报告差异，不能都归因为 Harness。
- [ ] 采用创建自身规则及已有 39 条取用，原规则结果与本项目采用规则结果分别保留；只声明直接完整生成路径，不冒充已比较草稿协作或其余 Skills。
- [ ] 使用已有材料失败、有效修复和 judge 误报作为回归样本，并加入未用于调提示的样本；不把参考输出或评阅答案交给被测生成流程。结果持久保存在本地，有来源、版本和规则身份，可被后续能力及 IM 评价复用。
- [ ] 报告实际内容、材料、修订和运行结果，未发生交互如实记录；严重数学、来源、人类与受众问题不由平均总分抵消。离线评价与真实 LangSmith 故障相互独立。
- [ ] 试运行保存多次执行的实际差异、失败和资源条件；不能凭一次成功声称稳定。用于广泛非劣声明的样本数与界限须在正式比较前依试运行依据确定，版本化保存，不在看到正式结果后调门槛。
- [ ] 人工评阅包包含原材料、规则、证据与独立填写入口；模型 judge 和数学教育评阅分别标记，分歧保留反例与裁定。
- [ ] 交付可重复命令／调用、实际试运行报告及明确未通过／未评阅范围。暂无专家时停留在准备和试运行结论，不伪造专家校准或教师使用证据。

## Reading and boundaries

读 [规格](../spec.md)、[验证路线](../../skills-harness/assets/validation-and-release-route.md)、[四项源码盘点](../../skills-harness/assets/skill-capabilities.md)、四项详细流程和原源码及 [上游评测说明](../../../k12-teacher-skills/evals/README.md)。

本票不等待其他能力；它也不能代替每项能力实现时的即时检查。新增课程体系没有同名上游 Skill，IM 内容评价复用评价记录与独立评阅入口，采用自己的课程判据。专家招募和真实学校试用是外部条件。
