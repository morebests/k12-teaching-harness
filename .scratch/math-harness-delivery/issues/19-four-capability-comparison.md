# 扩展并汇总四项 Skills 的实际对照证据

Status: needs-triage
Blocked by: [从课时创建开始建立可离线复现的 Skills 对照](11-skills-comparison.md)、[根据学习证据适配真实数学课时](08-lesson-adaptation.md)、[围绕真实任务完成教师参与的备课](09-teacher-preparation.md)、[生成并双重验证数学理解度检查](10-check-for-understanding.md)、[按真实草稿回应生成课时材料](16-lesson-draft-review.md)
Size: L/XL — 执行器可复用，但四种参考资源、交互和质量方差不同；当前是验证工作包。

## Ready condition

根据各能力实际规则取用、参考资源可用性、已有失败与试运行方差，收口本轮案例范围、重复方法、评阅工作和缺失条件，再决定是否按能力拆成独立验证票。不能现在承诺一张票完成普遍非劣证明，也不在看到正式成绩后调整门槛。

## What to build

沿已有离线对照框架加入适配、prep、CFU 和创建草稿协作，逐项记录其原规则、本项目规则、产出和真实交互差异，形成四项对照报告及人工校准材料。

## Acceptance criteria

- [ ] 每项能力用自己的完整上游规则与实际必需资源；缺失参考标为未复现，不能弱化基线。宿主适配、模型、工具及资料差异有清单。
- [ ] 对照和原创的输入／执行隔离；A 冻结前不运行需要目标 IM 材料的案例。该限制按具体案例决定，不把全部非目标案例都无谓阻塞到完整单元之后。
- [ ] 正常流程与必要例外、未用于调提示的自然语言改写、材料检查与修订均覆盖；不将创建 rubric 复制给其他能力。
- [ ] 同模型／可比条件优先，原宿主体验对照单列；模型评阅、确定性检查、真实人类和合成脚本分别标注。
- [ ] 保存实际重复执行、失败、质量与消耗，而不是仅提供执行命令；统计性结论受事先固定的样本和界限约束。
- [ ] 形成具体差异与严重问题清单，允许错误评价被反例推翻；分数不能抵消严重数学、来源、参与或泄题缺陷。
- [ ] 人工校准材料可交付，真实校准未发生就保持相应门槛未通过；本票能完成有边界的技术对照，不能冒称学校效果已验证。

## Reading and boundaries

读 [规格](../spec.md)、[验证路线](../../skills-harness/assets/validation-and-release-route.md)、各能力详细流程与原文、[上游评测说明](../../../k12-teacher-skills/evals/README.md)。本票不阻塞更早的创建比较，也不阻塞消费者契约验证；正式质量声明依赖本票及真实评阅门槛。
