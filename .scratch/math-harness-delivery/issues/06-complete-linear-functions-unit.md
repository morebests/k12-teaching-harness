# 完成线性函数整个单元的教学内容与检查

Status: needs-triage
Blocked by: [从全年蓝图交接到连续三课](17-curriculum-lesson-handoff.md)、[取消教学任务并续作明确停止的工作](05-stop-cancel-and-recovery.md)

Size: XL — 完整内容范围和实际修订工作尚需由连续课时结果确定；当前是交付工作包。

## Ready condition

连续三课和全年蓝图形成后，明确真实单元范围、产物清单、已见错误及可复用的批次生成／续作行为，估计剩余工程工作与内容审查工作。只对确实不能在一次开发上下文内闭合的部分继续拆票，再转为 `ready-for-agent`；不按每课或每条 rubric 预建生产节点。此状态不是因为有依赖，而是当前尚无法诚实地证明本票规模可控。

## What to build

把连续课时切片扩展到自有八年级线性函数单元的全部课段、课时、材料、练习与评测。课程负责人能够审查整个单元的学习进程和实际可实施性，不能由三课代表完整单元。

## Acceptance criteria

- [ ] 从自有全年蓝图和实际单元版本继续，保留目标、时间、入口／出口与各层 Narrative；不以 IM 单元序号、课段或课时数作为默认答案。
- [ ] 请求范围内的所有课时均有实际任务、解法、学生材料与必要资源；计划、已展开和已检查范围明确区分。材料缺失不能标为不适用。
- [ ] 逐项目标可回查学习机会和证据，实践标准通过实际学生行动体现；覆盖在合适层级判断，不让每课都承担全部单元目标。
- [ ] 检查表征含义、单位、练习与迁移的连续性；图中关系是设计依据，不能把每个邻接知识点都强行塞进课时。
- [ ] 区分诊断与达成性评测；后者依赖先前学习机会或真实先备证据。教师建议不能依赖已删除或尚不存在的后续练习。
- [ ] 按实际学生工作、讨论、转换与准备条件检查总容量和单课安排；50 分钟矛盾、无依据掌握度保证和标题代替内容等旧失败均被明确检查。
- [ ] 全范围实际渲染、数学检查与跨层审查产生版本化记录；发现问题修订并重查受影响内容，有阻断项时保留为未达标候选。
- [ ] 能保存并续作较长生成；原有三课不会因扩展重新失去有效内容和检查。完整单元状态只在全部请求范围满足后成立。
- [ ] 输出完整原创候选及其输入／工具／资源清单，可供后续冻结与对照；本票执行环境仍无对应 IM 参考。
