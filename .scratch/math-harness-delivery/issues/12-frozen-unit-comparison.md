# 冻结原创单元并完成匿名对照的第一轮评阅

Status: needs-triage
Blocked by: [完成线性函数整个单元的教学内容与检查](06-complete-linear-functions-unit.md)、[从课时创建开始建立可离线复现的 Skills 对照](11-skills-comparison.md)

Size: L — A 冻结、参考范围匹配和匿名首轮评价；实际 B 修订另行验收。

## Ready condition

取得完整原创 A 及其质量／资源范围后，再确定本轮可比范围、合法参考来源、评阅方式和输出清单。不得为提前收口本票而读取对应 IM 并污染尚未冻结的原创。明确模型评阅与专家评阅各自可取得的证据后转为 `ready-for-agent`。

## What to build

冻结原创全年相关蓝图和完整线性函数单元 A，再取得可比 IM 参考 R，形成独立匿名评阅包并实际运行首轮评阅。比较用于检验和增强本项目的课程设计能力；收到的有来源意见交给 [评阅后的修订](20-comparison-driven-revision.md) 生成 B，不能把“更像 IM”当目标。

## Acceptance criteria

- [ ] A 包含完整请求范围、实际输入／工具清单、内容指纹和质量报告；原始内容不可再原地覆盖。三课与目录不能作为完整原创冻结。
- [ ] 冻结记录保存已有修订与检查历史，但不把另一条“局部支持隔离”用例设为读取参考的前置；跨层修订能力和范围隔离仍是最终课程交付门槛。
- [ ] 仅冻结后在独立比较环境读取目标 IM 结构、Narrative、活动与评测；参考不回灌到 A 的输入，A／R／B 分开记录。
- [ ] 依据目标、先备、时间、资源和评测范围选择可比 R；不同部分逐项说明，不把相同“Unit 4”序号当可比条件。
- [ ] 保留题目和必要教学上下文，移除仅识别来源的包装，随机顺序并隔离标签映射；各评阅者先独立判断，不能先看到其他人评论。
- [ ] 用同一判据比较目标—机会—证据、进程、数学、认知要求及学校可用性；无效或不适用的参考建议可以拒绝并给出理由。
- [ ] 实际运行明确标注来源的独立首轮评阅，允许先模型、后专家；专家缺席时人工门槛保持未通过。预训练与结构泄露风险如实说明，不称严格双盲。
- [ ] 输出意见、具体材料引用、标签映射隔离记录与分歧，作为后续 B 修订的输入。本票不能在仅准备评阅包而没有实际首轮意见时声称首轮对照完成。
- [ ] 交付冻结证明、范围对齐、匿名材料、实际运行记录和待裁定项；广泛课程质量声明仍受人工校准及样本范围限制。

## Reading and boundaries

读 [规格](../spec.md)、[验证路线](../../skills-harness/assets/validation-and-release-route.md)、[课程能力](../../skills-harness/assets/curriculum-design-capability.md)、[已有验证设计](../../skills-harness/assets/grade8-linear-functions-validation-design.md)。

本票不依赖其余教学能力或完整产品 UI。准备阶段不能以需要分析参考为由提前向原创运行暴露 IM。实际人类评阅是交付门槛，不把系统生成的评语标为专家意见。
