# 在部署升级后正确恢复旧版本待答任务

Status: needs-triage
Blocked by: [在持久部署中重启和恢复实际教学任务](13-production-runtime-package.md)
Size: L — 两个实际版本的一次兼容升级；不预建任意版本迁移平台。

## Ready condition

取得首个持久部署和可演示的后继行为／资源版本，明确本次变化、兼容路径或迁移决定及回退范围，再转为 `ready-for-agent`。没有实际版本变化时不能靠空版本字段验收，也无需提前设计所有未来迁移。

## What to build

旧部署创建有具体展示对象的待答任务，升级后处理真实或明确标注的测试回应，保持原行为语义，或执行有记录的明确迁移；不默默以新规则解释旧的教师决定。

## Acceptance criteria

- [ ] 旧任务保存模型／规则／工具／状态和实际材料版本，有可执行的兼容路径或完整迁移记录。
- [ ] 在实际持久环境由旧版本创建待答、升级、提交回应并恢复；检查对象、决定、后续内容与预定语义一致。
- [ ] 验证迁移失败与回退、重复回应和未支持旧版本；保留原始事件，不以丢失任务或伪造新批准解决兼容性。
- [ ] 记录不能自动继续的情况及调用方可观察状态；确需新决定时展示具体变化后等待，不能静默越过 HITL。
- [ ] 交付升级与回退操作、实际结果和覆盖局限；版本字段存在、同版本重启或一份迁移设计文档均不能独立算作完成。
