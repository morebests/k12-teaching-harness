# 在权限撤销后隔离任务、材料和后台续作

Status: ready-for-agent
Blocked by: [直接生成一课的真实师生材料并检查修订](03-continuous-lessons-and-materials.md)、[在崩溃和调度结果不明后自动恢复任务](18-crash-reconciliation.md)
Size: M/L — 已有基本鉴权上验证动态撤权和受众边界，包含后台工作而非仅 HTTP 过滤。

## What to build

当可信调用方的材料或任务权限被撤销时，后续查询、下载、回复与后台续作都遵守新的有效权限；不同租户、教师和学生受众不会因缓存、链接或重启拿到不该看到的内容。

## Acceptance criteria

- [ ] 初始可信身份与任务／材料访问检查复用首票；本票不能成为此前允许跨租户访问的理由，不建设学校身份系统。
- [ ] 用真实师生材料验证教师答案／内部检查与学生页面的受众边界，原始 trace 和模型消息不成为旁路。
- [ ] 撤权后读取、事件提交、工具读取与最终内容提交重新核验；等待或运行中的任务在恢复后也不能沿旧授权继续产生有效副作用。
- [ ] 测试重复事件、已有产物引用、断流重连及缓存不会绕过权限，错误响应不泄露另一租户任务或材料存在性。
- [ ] 通过独立调用方和真实后台恢复测试记录证据；测试身份提供方与正式学校身份集成的范围分开。
- [ ] 接口文档明确可信权限输入及撤销后的行为，外部系统可按契约接入，不采信自然语言中的自称角色。
