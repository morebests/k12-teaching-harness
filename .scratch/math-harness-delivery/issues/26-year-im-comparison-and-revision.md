# 比较全年方案与 IM 并依据证据修订复评

Status: needs-triage
实施状态：待真实候选和校准结果收口，尚未评分。
Blocked by: [建立全年规划的证据评价与检查校准闭环](23-year-evaluation-and-check-calibration.md)、[补足所有单元的规划进程并核查全年连贯性](25-year-progressions-and-global-checks.md)
Size: 待实际候选和评阅结果确定 — 内容修订及方法验证不按固定调用轮数估算。

## 为什么做

对应 [规格 Y6，以及 Y1–Y5 的效果验证](../spec.md#问题价值与验证依据)。阶段化只能保证某些工作被组织和记录，不能自动证明课程规划接近 IM。必须在同尺度下读实际内容，显示哪一方更强、为什么、差距是否经过修订缩小。

还需区分两件事：新全年方案是否变好，以及改善能否归因于 Context 或 Graph。把新规则、新资料与新图一起换掉后只看一次结果，无法证明控制方式更优。

## 就绪条件

取得 25 的完整候选及 23 的实际检查校准报告，确认同尺度 IM 来源可取得的范围、评阅者可用性和待裁定问题。正式结果出现前，按试运行固定本轮比较／重复方法及可作的声明；需要大规模实验时另拆有明确问题的工作，不预建多套完整系统。专业评阅尚缺不阻止准备与模型辅助初评，其门槛保持未通过。

## 输入与交付

固定候选、来源、生成条件与规则版本；同尺度 IM 全年与单元规划资料；23 的证据评价入口及校准局限。交付逐维对照、重大问题与分歧、修订及复评、方法效果证据和下一步裁定。

## 验收条件

- [ ] 固定双方材料版本／取得日期、CCSS 范围、条件与证据深度，按数学职责对应，不按单元编号配对；规划层比较不要求本项目先生成全年 Lesson，也不单给 IM 全部 Lesson 深度。
- [ ] 如实记录已读 IM 及设计影响；候选冻结用于防止评分对象漂移，不伪称冻结前未接触参考。原候选、参考、评语和修订候选分别保存。
- [ ] 按八维协议完成对象级证据、覆盖及独立评阅；匿名和顺序交错不被称为严格双盲。每位评阅者不读取作者历史或他人结论，评分能回指双方实际内容。
- [ ] 显示各维更强、更弱、未见明确差异、未定或不可比的依据，重大问题优先；缺项、分歧、资源条件差异按协议处理，不给 IM 自动满分，不用总分掩盖关键差距。
- [ ] 将成立发现交回负责的 A／B／C 阶段核实和修订，重做 D 及受影响检查；拒绝建议需实际依据。保留未改内容的质量，按同一规则重评双方；规则改变时另存版本并重评。
- [ ] 具体报告修订前后哪些目标、进程、练习、评价或可行性问题改善，哪些仍弱或未定；没有实际修改需要时记录证据，不为展示流程强制改坏合理内容。
- [ ] 方法验证以全年规划为任务，优先复用既有实现作最小可比试验：充分输入的原循环、改善 Context／判据的循环、同条件的显式阶段控制分别记录。模型、资料可得范围、工具及外部评价条件对齐，无法控制的差异明确列出。
- [ ] 保留失败和未调提示的新情境，报告遗漏、误报、过期结果、修订保真、返工及达到相应质量的实际消耗。单次旧新比较只能说明样本变化；试运行后才能在预定条件下重复并限定方法声明，不把 Graph 增益预设为正。
- [ ] 独立复核不足时报告模型辅助初评；未取得的专业或教师证据不得虚构。检查失败、不可观察及未决关键差距持续阻止相应质量声明。
- [ ] 输出三个分开的结论：工程是否完成、全年规划质量是否达到当前门槛、哪些方法得到何种证据支持。依据 [规格验收门槛](../spec.md#验收与质量声明)决定继续全年修订还是具备后续迁移依据，不能仅以本票代码完成恢复 03／17／06。

## 边界与后续

全年内容比较与方法因果验证分别报告，不用工具调用数衡量教学质量，也不拿课堂学习效果作未取得的证明。没有新证据支持的机制只保留为候选；证明有用后，03／17 等按自身教学流程检验迁移效果。12／20 仍承担未来完整单元的比较，不由本票替代。
