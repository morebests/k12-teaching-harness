# 从外部后端调用五项能力并核对交付边界

Status: ready-for-agent
Blocked by: [按自然语言修改课程并重查受影响内容](07-scoped-curriculum-revision.md)、[根据学习证据适配真实数学课时](08-lesson-adaptation.md)、[围绕真实任务完成教师参与的备课](09-teacher-preparation.md)、[生成并双重验证数学理解度检查](10-check-for-understanding.md)、[按真实草稿回应生成课时材料](16-lesson-draft-review.md)

Size: M — 汇总已随各能力维护的服务外调用示例，验证五项消费者契约；不首次开发所有接口。

## What to build

用独立后端调用方完成五项能力的任务生命周期，展示可交付材料和真实待答，取得用于外部课程采纳、追溯和治理的证据。各票已随功能维护外部调用例；本票汇总五项并检查漂移。使用已有全年蓝图、连续课时和各能力代表对象即可验证协议，不等待完整单元内容达标或目标生产环境。

## Acceptance criteria

- [ ] OpenAPI 与实际实现一致，示例调用方仅使用公开任务和产物入口，不依赖内部 Python 对象、checkpoint 格式或 Agent 客户端。
- [ ] 五项能力分别从真实授权输入运行到相应产物／待答／停止，验证自己的退出条件；未完成、待后审、已接受与已交付不会被统一成一个成功标志。
- [ ] 自然语言回应、修改、续作、取消、重送及流重连可通过该调用方完成；教师只需理解当前任务和问题，无需记住场景清单。
- [ ] 课程、学习证据和 Learner Model 输入使用真实版本与范围；不能要求外部系统为了本 Harness 重建其身份或学习者模型。
- [ ] 下载或展示材料遵守受众与权限；产物、规则、来源、人类决定、检查和版本变更可由调用方完整追溯。
- [ ] 公共基线采纳以外部所有者的条件提交结果为据；接口不自动发布教学内容或把工作版本误标为学校已采用。
- [ ] 文档包含启动、配置、支持范围、正常和错误调用、典型待答与恢复以及证据读取。明确不支持格式／模型和尚未验证主题。
- [ ] 交付记录关联各实现票和实际验收材料，质量比较／人工评阅／真实部署／学校使用缺口分别列示；技术集成通过不写成全项目质量完成。
- [ ] 若仅有测试后端，明确这是消费者契约验证；实际 Web 产品接入和真实用户操作仍待外部系统完成，不用本票假造试用证据。
