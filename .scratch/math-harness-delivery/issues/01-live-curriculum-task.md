# 从任务接口完成有明确范围的真实课程设计

Status: ready-for-agent
Blocked by: None

实施状态：已完成本票有限范围（2026-09-15）；triage 保留原就绪标签。

Size: L — 首次贯通真实模型、知识、原生开发服务与当前内容保存；只验收一个有限课程设计任务。

## What to build

产品后端提交明确授权的八年级线性函数课程设计请求，经真实 Gemini、原生 LangChain 模型／工具循环与本地 LC 得到文件化的当前课程方案及检查记录。首例设计一个课段的目标、进程、Narrative 与关键任务构想，查询其实际内容和未完成项；不要求本票同时解决完整全年覆盖。

首例使用已有合成学校条件与明确的 CCSS 目标，运行不读取目标 IM。它仍是课程设计能力的有限调用，不是计算器或假数据脚手架；临时课段不是正式全年方案，不能直接充当连续三课的权威上层。完整全年设计由 [全年蓝图](15-full-year-blueprint.md) 承接，再由 [连续课时交接](17-curriculum-lesson-handoff.md) 使用真实上层结果。

## Acceptance criteria

- [x] 发起／查询通过 Agent Server 原生 API／SDK，教学输入输出采用真实类型并提供可查阅契约；符合 [规格当前阶段](../spec.md#当前阶段文件化教学内容闭环)。不另造一套会话／run 服务。未实现能力明确返回不支持，不接受后输出伪结果。
- [x] 通过 Agent Server dev 执行，一个教学任务对应一个 thread，同线程采用明确的并发拒绝策略；不自建队列、全局忙调度器或 SSE 服务。前端从原生流得到实际步骤、可展示草稿、检查进度与结果，草稿标为未检查，不透传原始消息或私有推理。断流后查询已有 thread／run，不自动重发生成；完整生产故障验收后置。
- [x] 重送发起事件返回同一任务；同事件不同正文返回冲突。可信调用身份与 Context 来源被记录，正文不能自授权限。
- [x] 使用真实 Gemini 原生循环与真实工具，经 LangGraph／Agent Server dev 承载；运行状态使用服务注入的 checkpointer，当前教学内容另存文件，查询不触发模型。建立可重复的依赖安装、版本锁定和 `langgraph dev` 入口，不依赖固定答案；不另配业务数据库、独立 PostgreSQL／Redis 或文件运行状态机。
- [x] 本地 `browse` 取得本次目标的真实 CCSS、相关实践要求、Learning Components／进阶关系；所用查询的分页、图方向、身份与数据版本有证据。明确仅覆盖本次目标；全年范围完整性由全年蓝图票验收。
- [x] 模型实际得到任务规则、学校条件和适用知识；Context 清单含内容版本。工具及输入阻止对应 IM 内容进入原创运行。
- [x] 实际课段方案包含目标职责、学习进程、Narrative、先备与后续以及用于试查可实施性的关键任务构想；不能只有目录，不宣称已有全年覆盖或完整单元材料。
- [x] 按 [文件化格式](../content-system-design.md) 保存可读的当前 JSON 方案与实际检查；内容变化使旧检查失效，重查后才能显示当前稿通过。同目录串行写入、写完整再替换；检查本次目标遗漏、数学问题和课堂条件，发现问题修订。接收调用方已规范化的实际文本／结构内容、来源与指纹，后续 prep 不依赖生成器；任意上传格式、内容历史和回滚不在本票。
- [x] 从本票记录模型／规则／工具版本、调用与消耗、源资料、产物和检查；敏感配置不入日志。提供明确资源上限与保存未完成成果的停止行为，不沿用 12／24 为默认常量。
- [x] 用独立调用方示例经 API 覆盖重送、缺失知识、坏产物引用和越权读取；真实模型运行留下内容与检查证据。后续票扩展示例，不等最终集成才第一次从服务外调用。

## Reading and boundaries

用户于 2026-09-15 要求本轮方案定稿、提交并推送，[交互原型基准](../prototype-baseline.md) 作为现行参考随本轮保存。完成此次提交／推送后不再索取同一规划确认；按文件化阶段落实功能，不将原型历史演示带入首阶段。原型保存在 `codex/planning-handoff` 分支及所链接路径，不从固定样本复制生产逻辑。

先读规格，再读 [课程能力决定](../../skills-harness/issues/12-curriculum-design.md)、[课程详细设计](../../skills-harness/assets/curriculum-design-capability.md)、[Context 设计](../../skills-harness/assets/context-and-llm-design.md)、[模型／工具设计](../../skills-harness/assets/model-knowledge-artifact-design.md) 与 [知识使用约定](../../../docs/references/knowledge-consumption-contract.md)。参考 [已有真实实验](../../skills-harness/experiments/grade8-linear-functions/README.md) 及失败记录。

本票按 [规格的当前阶段](../spec.md#当前阶段文件化教学内容闭环) 使用原生开发服务与文件内容，不引入业务数据库或外部 authoring，不另开完整内容平台前置票。真实人类等待后续使用框架 interrupt／resume；复杂故障恢复和平台 trace 分别扩展。本票必须如实标注尚不支持的路径，框架已有能力不重新立项自建。

输出给后续票的是实际任务／事件身份、当前内容读取与指纹、检查记录、适用知识结果、最小可信访问边界和模型／工具循环。当前不承诺旧内容指纹可回取历史正文。只固定已需要的交接，不预建通用内容平台。若这一有限路径仍超出一次完整开发上下文，按真实适配失败再细拆，不删去内容与检查验证来凑规模。

## Comments

### 2026-09-15：维护者诊断的环境与权限要求

用户要求初始开发阶段提供追踪，生产可关闭，但有权限的维护者必须能够按配置查看。依 [规格补充](../spec.md#4-任务级调用约定)，新增诊断开关与可信维护者名单，复用原生模型／工具流和只读状态接口；任务归属检查继续生效。生产默认关闭详细诊断，开发启动提供开启默认，实际查看还须维护者资格；基础执行证据保留。取消硬编码的 LangSmith 关闭，尊重服务端配置，提供原生诊断流保存示例。此项不等于完成平台接通验收或上一轮建议的阶段图重构。实施与验证见 [维护者诊断记录](../evidence/01-live-curriculum/maintainer-diagnostics.md)。

### 2026-09-15：当前阶段改用文件工作稿

用户要求自行确定格式，暂不上数据库、不做版本历史。本票采用 JSON 当前工作稿及指纹关联检查。经随后对框架能力的核查，撤回文件运行状态与手写后台服务候选，直接使用 LangGraph＋Agent Server dev；框架 checkpoint 保留。业务数据库／不可变内容历史／完整生产持久恢复留待后续。教学目标、真实模型、本地知识、检查修订与调用入口保留；本票通过不代表已有生产持久运行。

### 2026-09-15：首个可执行工作

最初将全年蓝图与首次运行贯通合在一票；本次规模复核后将全年范围移交独立票，保留真实课程工作作为首个贯通对象。详见 [逐票复核](../ticket-sizing-review.md)。


### 2026-09-15：完成有限真实课程闭环

已交付原生 dev 服务、可信身份与事件重送、真实 Gemini／LC、当前 JSON／图件／阅读稿、隔离检查与反馈修订、资源停止和外部规范化内容入口。最终真实任务 `e0d8ee31-4157-560f-be9a-17c72eab31ab` 形成 3 课时、6 项关键任务，当前指纹检查通过；它不是正式全年／单元上层。

[验证报告](../evidence/01-live-curriculum/README.md) 保存真实通过结果及此前失败：Schema 适配、资源触限、图件问题与修订、取消后重启重放。应用已保护累计用量并停止自动重放，未声明生产取消持久性或受控续作完成。独立客户端 API 测试覆盖重送、缺知识、坏引用、越权、流式与停止；规范／规格两轴发现均已修复。

运行与可查契约见 [运行说明](../../../docs/runtime.md)，实际结果见 [当前课段](../evidence/01-live-curriculum/e-completed/api-result.json)。浏览器策略拒绝直接打开本地 HTML，本轮仅完成文件与图件一致性核验，浏览器视觉验收、教师校准与课堂效果均未通过；后续能力与生产票范围保持不变。

### 2026-09-15：用户质疑后的编排与调用证据复核

重新核对官方文档、锁定源码及实际事件后，确认当前外层单节点未充分表达已有的生成、独立审阅、检查提交和反馈修订阶段；使用 `create_agent` 与 LangGraph 可以合理组合，但 Agent Server 并不要求额外的单节点包装。既有设计中的“能力流程内模型循环”仍是方向，当前实现没有充分落实。具体建议与恢复边界见 [职责边界复核](../../skills-harness/assets/react-and-workflow-boundaries.md)。

[真实工具序列复核](../evidence/01-live-curriculum/tool-sequence-review.md) 列出 E 的 23 次工具事件与已知结果；没有 Agent 执行标识和工具调用关联，读取结果及失败细节存在缺失，不能完整回答一次 Agent 执行的全部工具输入输出。此前有限产物通过与 API 结果仍是事实，但不能据此宣称编排和观察设计已充分验收。后续需把已知阶段与执行关联落实并验证；本次只记录调查结果，没有改运行代码、重跑模型或启用 LangSmith。

### 2026-09-15：阶段图重构的目标设计

### 2026-09-16：撤销自设 token 拦截，完成材料修复与实际走查

用户指出此前已约定先完成高质量任务再观察消耗，且格式问题应参照 Skills 修源、重渲染、核对实际输出。撤销示例的累计 token 阈值和按字节预留逻辑，默认仅累计供应商实际用量；兼容调用方显式阈值，不拦截已经完成审阅后的纯程序检查提交。Gemini adapter 的 `count_tokens` 能力已核对源码、官方资料并实际调用，文本探针为 13 tokens。

根因是同段 `$$` 被错误匹配成行内公式，随后中文被交给 KaTeX；已修复解析，并把源字段、公式和原因反馈给作者。未闭合公式和常见命令重复转义的补充反例也有具体反馈。真实草稿重渲染、真实 Gemini＋LC 修订、独立审阅及浏览器检查已完成；最后一稿含 120 个 MathML 公式、20 个分式、1 张表格和1个 SVG，在所查桌面视口无横向溢出。格式修复任务用 410,455 tokens，走查后的内容修订用 533,823 tokens，均未设置累计 token 预算；不会把两次接续修订的用量说成从零生成成本。完整结果、工具请求／返回、审查与局限见[修复证据](../evidence/01-live-curriculum/render-repair/README.md)。

### 2026-09-16：纠正当前产物的产品定位，准备原 Skills 对照

用户指出独立课段混入完整题目细节，缺少全年体系和可直接使用的 Lesson。核查确认：当前只有 Section 和简化 LessonIntent，正式 Grade／Unit／Lesson 交接未实现。本票完成的是有限工程验证，不是五项能力或完整课时材料交付；阅读稿格式通过也不能作为教师可用性结论。后续落实既定全年蓝图、单课材料与跨层交接，不继续扩展孤立课段报告。详见 [范围复核](../ticket-01-scope-and-comparison-review.md)。
