# 从任务接口完成有明确范围的真实课程设计

Status: ready-for-agent
Blocked by: None

Size: L — 首次贯通真实模型、知识、持久任务与内容提交；只验收一个有限课程设计任务。

## What to build

产品后端提交明确授权的八年级线性函数课程设计请求，经真实 Gemini、原生 LangChain 模型／工具循环与本地 LC 得到版本化的有限范围课程方案及检查记录。首例设计一个课段的目标、进程、Narrative 与关键任务构想，查询其实际内容和未完成项；不要求本票同时解决完整全年覆盖。

首例使用已有合成学校条件与明确的 CCSS 目标，运行不读取目标 IM。它仍是课程设计能力的有限调用，不是计算器或假数据脚手架；临时课段不是正式全年方案，不能直接充当连续三课的权威上层。完整全年设计由 [全年蓝图](15-full-year-blueprint.md) 承接，再由 [连续课时交接](17-curriculum-lesson-handoff.md) 使用真实上层结果。

## Acceptance criteria

- [ ] 发起／查询符合 [交付规格](../spec.md)；由实际请求和响应类型生成可查阅的 OpenAPI。未实现能力明确返回不支持，不接受后输出伪结果。
- [ ] 重送发起事件返回同一任务；同事件不同正文返回冲突。可信调用身份与 Context 来源被记录，正文不能自授权限。
- [ ] 任务经 Agent Server／LangGraph 持久承载，使用真实 Gemini 原生循环与真实工具；查询不触发模型。建立可重复的依赖安装、版本锁定和本地运行入口，不依赖原型的固定答案。
- [ ] 本地 `browse` 取得本次目标的真实 CCSS、相关实践要求、Learning Components／进阶关系；所用查询的分页、图方向、身份与数据版本有证据。明确仅覆盖本次目标；全年范围完整性由全年蓝图票验收。
- [ ] 模型实际得到任务规则、学校条件和适用知识；Context 清单含内容版本。工具及输入阻止对应 IM 内容进入原创运行。
- [ ] 实际课段方案包含目标职责、学习进程、Narrative、先备与后续以及用于试查可实施性的关键任务构想；不能只有目录，不宣称已有全年覆盖或完整单元材料。
- [ ] 保存可读的不可变方案与检查引用后才提交交付版本；检查本次目标遗漏、数学问题和课堂条件，发现问题进行修订。通用内容引用可接收调用方已规范化的实际文本／结构内容、来源与指纹，后续 prep 不依赖教案生成器才能读取原课；任意上传格式解析不在本票。
- [ ] 从本票记录模型／规则／工具版本、调用与消耗、源资料、产物和检查；敏感配置不入日志。提供明确资源上限与保存未完成成果的停止行为，不沿用 12／24 为默认常量。
- [ ] 用独立调用方示例经 API 覆盖重送、缺失知识、坏产物引用和越权读取；真实模型运行留下内容与检查证据。后续票扩展示例，不等最终集成才第一次从服务外调用。

## Reading and boundaries

本票开工前还须完成用户要求的规划提交／推送和 [交互原型基准](../prototype-baseline.md) 确认。当前候选待确认；这是实现前的一次共同检查，不给每张票新增一套审批。原型保存在 `codex/planning-handoff` 分支及所链接路径，不从固定样本复制生产逻辑。

先读规格，再读 [课程能力决定](../../skills-harness/issues/12-curriculum-design.md)、[课程详细设计](../../skills-harness/assets/curriculum-design-capability.md)、[Context 设计](../../skills-harness/assets/context-and-llm-design.md)、[模型／工具设计](../../skills-harness/assets/model-knowledge-artifact-design.md) 与 [知识使用约定](../../../docs/references/knowledge-consumption-contract.md)。参考 [已有真实实验](../../skills-harness/experiments/grade8-linear-functions/README.md) 及失败记录。

本票包括贯通所必需的最小任务和内容存储，不另开“先建数据库／先写 Prompt”横向前置票。真实人类等待、复杂故障恢复和平台 trace 分别扩展；本票必须如实标注尚不支持的路径。

输出给后续票的是实际任务／事件身份、不可变内容引用及读取、检查记录、适用知识结果、最小可信访问边界和模型／工具循环。只固定已需要的这些交接，不预建通用内容平台。若这一有限路径仍超出一次完整开发上下文，按真实适配失败再细拆，不删去内容与提交验证来凑规模。
