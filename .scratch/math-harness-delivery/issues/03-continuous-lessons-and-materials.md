# 直接生成一课的真实师生材料并检查修订

Status: ready-for-agent
Blocked by: [从任务接口完成有明确范围的真实课程设计](01-live-curriculum-task.md)

Size: L — 首次材料源、受众视图、数学／渲染检查；限定为一课的已授权完整生成。

## What to build

调用方提供实际课程上下文或明确的独立课时目标，并已授权直接生成完整材料。Harness 完成一课教案、学生材料和学习检查，经实际渲染与修订后交付。草稿协作由 [草稿审阅](16-lesson-draft-review.md) 承接，全年到连续三课的关系由 [课程交接](17-curriculum-lesson-handoff.md) 承接。

## Acceptance criteria

- [ ] 使用实际父级内容时保留版本及课时职责；独立课时使用明确目标和真实条件，不虚构已有全年课程。首次可用合成但明确标注的调用方上下文验证本接口。
- [ ] 运行时实际装配原创建流程与数学要求的采用资源，继承全部 39 条 rubric 映射；固定数量、IM 课堂动作及整单元覆盖不强加给每课。
- [ ] 真实任务、解法、学生推理、代表性困难、教师提问／讨论、学习检查和响应建议齐备，不能用题型说明或提示词替代题目。
- [ ] 本票支持已有完整生成授权的直接路径，不重新索要授权；需要草稿协作的请求在相应票完成前明确不支持，不能擅自改为直接生成。
- [ ] 使用实际内容源生成教师与学生视图，提供不可变产物引用与可编辑源；共同内容一致，学生页无答案、教师说明或能力标签泄漏。
- [ ] 必要函数图实际生成并验证数学、坐标／单位／标签与可读性；实际 HTML／SVG 渲染和浏览器页面走查均完成，不能以源代码检查替代页面。
- [ ] 创建型学习检查能暴露目标错误方法；课堂安排考虑学生工作和讨论等实际耗时。复测旧实验的图形、时间、未渲染自报和无依据效果声明问题。
- [ ] 问题回给模型核实和修订；误报可用计算或原文反驳，改后重查实际版本。交付包含检查证据和未解决项，严重问题阻止对应交付。
- [ ] 请求格式不支持时明确返回限制，不能默默改变格式；只声明本课范围，不把单课判为课程体系已贯通。
- [ ] 经同一任务 API 演示直接生成、检查失败反馈和实际材料修复；保存真实模型完整内容运行及服务外调用证据，自动测试和教学质量分别裁定。
