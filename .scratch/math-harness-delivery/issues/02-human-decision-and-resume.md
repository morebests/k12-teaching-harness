# 让真实教学决定跨进程等待并恢复执行

Status: ready-for-agent
Blocked by: [从任务接口完成有明确范围的真实课程设计](01-live-curriculum-task.md)

Size: L — 新增回应解释与持久采纳，但限制在一个实际课程取舍的完整等待／恢复路径。

## What to build

在实际课程设计任务中，遇到缺失且影响方案的条件或超出授权的课程取舍，展示具体内容并等待人类。外部后端提交真实回应后，Harness 保存原文、解释决定、按有效范围恢复；已有决定直接使用。无需用户选择内部场景名称。

## Acceptance criteria

- [ ] 待答含目的、问题、实际内容、对象版本和展示快照；调用方可以仅靠返回内容展示并收集自然语言回应。
- [ ] 当前已有授权的正常案例自主完成；确需课程取舍时才等待。不能为了测试而给每层课程添加审批。
- [ ] 真实回应先保存，再解释其范围；采纳动作和待续作标记在业务事务内提交。接收、采纳与续作各有可观察状态，202 回执不冒充已完成。
- [ ] 同一事件重送不重复执行；新事件中的否定、附带条件和改变决定不会因旧请求已消费而丢失。展示仍有效时，单纯进度版本增加不拒绝回复。
- [ ] 已采纳动作的下游重试复用采纳记录；不会把原文重新解释成不同决定。调度结果不明先核对 Server run，再安全重试。
- [ ] 等待时真实进程退出，使用一次真实用户回应恢复并产生实际方案变化；测试事件与真实参与分别标注，不用模型扮演用户过关。
- [ ] API 行为用例覆盖受控等待重启、重送、过期对象、简短回应与新意图；固定案例之外保留未用于调提示的自然语言改写。原文保存→采纳→调度各窗口的自动崩溃恢复系统性验收由 [故障恢复](18-crash-reconciliation.md) 负责，持久动作／待续作事务仍必须在本票实现。
- [ ] 原文、决定、产物及检查版本可追查；没有回应时继续等待，不以超时产生批准。

## Reading and boundaries

遵守 [规格](../spec.md)、[HITL 决定](../../skills-harness/issues/07-hitl-protocol.md)、[HITL 详细分析](../../skills-harness/assets/hitl-design.md) 及 [主执行设计](../../skills-harness/assets/main-execution-design.md)。[持久探针](../../skills-harness/assets/cfu-durable-prototype-results.md) 只提供有限先例。

本票交付真实任务的回应与恢复机制。后续三项教学能力仍须实现自己的参与语义，不能以本票一次确认替代备课贡献或适配整套接受。

## Comments

### 2026-09-15：界定恢复责任

本票拥有真实等待、原文／语义采纳和受控重启；取消／续作与系统性硬退出分别由后续票扩展。真实参与是本票明确的外部验证输入，实际缺席时保留待验证，不把合成回应算作真人。
