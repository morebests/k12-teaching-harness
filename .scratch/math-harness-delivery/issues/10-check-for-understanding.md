# 生成并双重验证数学理解度检查

Status: ready-for-agent
Blocked by: [直接生成一课的真实师生材料并检查修订](03-continuous-lessons-and-materials.md)、[让真实教学决定跨进程等待并恢复执行](02-human-decision-and-resume.md)

Size: L — 一个焦点的学生页、指南和两道验证；保留为一个不可缺检查的交付单元。

## What to build

教师从 CCSS 标准、焦点或实际课程任务发起理解度检查，Harness 使用真实 Learning Components、前后进阶和相关错误分析，生成学生页与教师解释指南，对实际文件完成两道验证并修复问题。

## Acceptance criteria

- [ ] 调用可仅给标准与教学目标，不要求原教案；本票依赖创建票提供的实际产物／受众渲染机制，不代表教学输入依赖。
- [ ] 实际取得并审视相关 LC、标准原文与前后联系，保留版本和采用理由；已有有效焦点直接用，缺少选择才提出简明待答，明确改向后不再次索取同一批准。
- [ ] 运行时采用 CFU 原流程、数学构建及验证资源，形成自己的逐条映射；先建立错误模式—题干特征关系，再构建任务与实际回应解释。
- [ ] 题型和表征符合目标认知要求；学生要显示思考，包含能够识别答对但推理有缺口的情况，教师指南给出可观察作答与具体后续方向。
- [ ] 实际写入学生页与教师指南后，才对这些内容执行完整验证；程序保证顺序和对象，不接受模型一句“已验证”。
- [ ] 独立读者只能看完整学生可见内容，包括图题、描述与格式，不能看答案、生成历史和缓存；逐项判断可辩护回答。单选检查唯一性，多选／开放题按自己的判据。
- [ ] 第二道验证以题目实际数量和条件推演每种错误／回应，核对是否到达对应选项或回应类型；教师指南和学生页内容及选项顺序一致。
- [ ] 修复、替换题目后重写所需产物并重查受影响项；误报可据计算与原文裁定，未解决阻断项不得交付。
- [ ] 实际数学、图形、语言与可读性合格，学生视图无答案提示和诊断标签；使用原规则与本项目采用规则分别报告结果。
- [ ] 通过 API 覆盖有效焦点复用、真实选择／改向、两个可辩护答案、干扰项不可达及答对但理由错等反例；真实生成和固定验证样本分别标注。
