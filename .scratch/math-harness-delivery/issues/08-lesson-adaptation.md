# 根据学习证据适配真实数学课时

Status: ready-for-agent
Blocked by: [直接生成一课的真实师生材料并检查修订](03-continuous-lessons-and-materials.md)、[让真实教学决定跨进程等待并恢复执行](02-human-decision-and-resume.md)

Size: L — 限定一节真实课的支持／拓展与本次请求材料；不同时建设任意核心题目变体或学习者建模。

## What to build

教师选择已有真实课时并提供相关学习需要，得到保持数学目标的入口、支持、支架和拓展，以及协调的教师说明与学生材料。正常协作支持逐部分修订和整套接受；显式要求只生成供后审时无需假造接受。

## Acceptance criteria

- [ ] 可使用本 Harness 的真实课时或有权限的外部原课快照；读不到原文时说明缺口，不将标题或主题臆造成原课，也不重新索要已提供内容。
- [ ] 装配并记录适配原流程、数学 R1–R8、知识与输出规则的采用映射；逐项说明原目的、保留／调整和检查，不能直接套用创建 39 条。
- [ ] 实际学习证据、Learner Model 相关状态和未知项分别处理，知识图与研究因素不冒充学生实测结果。支持与拓展的具体变化可追查依据。
- [ ] 保持本课数学目标和有意义的共同任务；支持引导学生完成目标工作，不靠删掉难点、忙碌练习、关键词策略或泄露答案降低要求。
- [ ] 首批共同核心题目与支持／拓展成套生成；核心题目变体明确区分并独立验算，不被共同引用静默覆盖。不支持的变体范围如实返回，不把它永久禁止为教学原则。
- [ ] 教师说明与纯学生材料协调、实际渲染可用；学生页使用中性称谓，无能力标签和教师诊断说明。所需份数由请求与用途决定，不把四文件规则推广到全部能力。
- [ ] 分开持续性支持与可撤除支架；不自动改变公共课程基线。来自下层试做的课程问题单独提出，不借适配偷偷重写上层课程。
- [ ] 正常协作积累对仍有效部分的接受，整套接受绑定当前请求范围与版本；部分接受、待后审、退出和沉默分别处理。通用任务取消由取消票提供，集成时复验本能力遵守它，不在本票重复建设取消承载。
- [ ] 检查实际数学、支持有效性、认知要求和材料一致性；问题回给模型修复。API 验证真实原课、个体变化、部分／整套接受及主动后审路径，记录真实生成证据。
