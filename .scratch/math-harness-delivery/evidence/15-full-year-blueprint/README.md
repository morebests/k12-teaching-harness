同一 Agent Server 原生任务入口已支持 `scope=year`：遍历真实八年级 CCSS 范围，生成全年单元组织与目标分配，检查并修订实际内容，返回带指纹的单元交接。三轮真实 Gemini 运行保留了初稿、具体反馈与最终结果。

- [最终全年阅读稿](final/output/curriculum.html)、[JSON 工作源](final/content/curriculum.json)：8 个单元，160 节常规课时＋20 节机动课时，每节 50 分钟。33 项叶标准、3 项父标准分别分配职责，MP1–MP8 有学生行动与评价依据。父标准不重复计入 33 项叶目标。
- [线性函数单元交接](final/unit-handoff.json)：本设计的第 3 单元，共 22 课时；包含实际目标、Narrative、前后单元、学校条件、相关标准及必要祖先、知识记录、探查、SVG 正文与参数。全年指纹为 `b1351a76cc1323cbdccc0717a2e3f393943f9e7ee733fc135aaff55a047b8d2d`，交接指纹为 `01ed6ffb259455cff588408b6f82ac95426f4a70cc982ac92d631c181f73700a`。
- [当前检查](final/checks.json) 与 [人工核读](manual-review-final.md)：最终程序及独立模型检查通过，前两轮人工指出的具体问题已修订。该结论限于全年蓝图与关键任务探查。

全年使用已有实验的**合成学校条件**：28 人，纸笔、直尺、方格纸、黑白打印、教师投影、普通计算器；没有实际学生诊断。目标 IM 内容未读取。尚未交付全年逐课材料、完整 Lesson、教师校准或课堂效果证据。

## 知识范围与执行机制

[实际知识记录](final/knowledge.json) 保留 `lc/v1.11.0` 源指纹、固定 CCSS 身份、年级投影、层级、分页、排除与采用条目。本次返回 71 个年级投影节点：含 33 个叶目标、3 个有整体职责的父标准，以及通用 MP／八年级 MP 原文。节点数来自服务动态返回，不是代码验收常量。

完整遍历逐层核对分页与动态计数。正式运行使用默认页容量；另用真实服务、`page_size=7` 留下 [分页探针](real-pagination-probe.json)，218 次读取中有 2 个 `hasMore` 页。空集、缺页、服务错误和年级投影排除的不同处理由知识 HTTP 及正式图测试覆盖，不伪造生产故障记录。

继续复用 `prepare_task → author → prepare_review → reviewer → record_review`。范围准备、检查与条件路由由普通 Python 执行；作者和独立审阅使用静态 Agent。真实工具顺序、参数和返回分别见 [初稿](initial/tool-execution.json)、[修订](revision/tool-execution.json)、[最终运行](final/tool-execution.json)。这是观测记录，Agent 的选择并非固定编排步骤。

例如最终运行：作者先制图、读取当前稿、查询 `8.F.B.4` 前序关系、保存及自查；第一轮送审被程序指出本次查询缺少采用条目的证据后，回到作者，补查 `8.F.B.4` 后继、`8.EE.B.6`／`8.EE.C.8`／`8.G.B.6`／`8.SP.A.3` 前序和 `8.EE.C.7`／`8.G.A.1` 组件，核对图件指纹，再保存并独立审阅。所有 21 次工具调用均在上述文件中，包含重复及被拒绝的调用。

运行使用 Gemini `gemini-3.8-flash`，LangChain 1.4.0、LangGraph 1.2.11、Agent Server 0.14.1、Google adapter 4.4.0。每轮 `context.json` 保存实际规则正文、版本、来源及规范化输入。运行服务为本地 `langgraph dev`；本轮使用维护者本地原生诊断，未验收 LangSmith 云端关联或生产恢复。

## 失败和修订

1. **初稿**：模型给出空 findings，但人工发现请求外器材、无实际数据的统计任务、关联与因果混淆、无限外推和学习效果夸大；见 [第一次反馈](manual-review-1.md)。初稿的模型检查原样保留，不能据其 `passed` 将它作为最终交付。
2. **修订**：以初稿实际 JSON、SVG 和指纹作为新任务来源。程序阻断未在本次查到的知识 ID，作者补查后重新送审。人工末读仍发现统计数据范围与截距解释不一致，以及表头裸 LaTeX；见 [第二次反馈](manual-review-2.md)。
3. **最终运行**：沿用实际修订稿，统一统计范围为 1–7 小时，明确教学合成数据与模型关联含义，区分域外截距和样本支持的预测，修复表头公式。来源检查再次触发补查后通过；最终核读见 [结论](manual-review-final.md)。

本轮修复了真实模型适配与验证缺口：Gemini 工具转换未保留单值 `const` 时显式提供 `enum`；格式检查增加公式标记外的 LaTeX 命令识别；中文外部源按实际 UTF-8 字节计量。保存或渲染错误返回具体问题并继续修订，没有把格式错误当作完成。

[逐调用用量审计](usage-audit.json) 从原生记录中的完整 AIMessage 去重取得供应商 `usage_metadata`，并与执行计量逐项核对；不能把流式增量重复求和。缓存读取已包含在输入中，推理 token 已包含在输出中；未取得账单，不推算费用。缓存命中是本次供应商返回的观测值，不保证下次命中。

修订是**带旧稿和图件的新原生任务**，不是旧检查点续作。已有设计被复用，模型仍重新读取上下文、补查来源和审阅，旧调用消耗保留在总账中。完整蓝图、标准、规则与工具结果在多次调用中重复进入上下文，累计输入较大；本票没有实施缓存或 Context 精简优化。没有默认累计 token 预算；请求中模型／工具／活动时间上限分别为 100／300／7200 秒，三轮均未触及。单消息输出容量 32,768 仅用于容纳全年工具参数。

- 全套测试一次：**83 passed**；随后新增裸 LaTeX 回归，受影响文件 **14 passed**。Ruff、mypy、契约导出和差异空白检查通过。
- [双轴代码审查](code-review.md)：规范与规格各发现 2 项问题，修复后复核均无遗留。测试包含实际原生 API、跨身份／旧指纹、草稿交接状态、图件与层级交接、知识故障、Schema 转换及 CLI 来源输入。
- [最终实际 API 验证](api-verification.json)：当前内容、单元交接、契约和阅读稿读取成功；过期指纹返回 409；API 阅读稿与导出文件逐字节相同。
- 浏览器打开本地阅读稿被工具的 URL 策略拒绝；没有绕过该限制，**未完成浏览器视觉验收**。已核对源内容、数学、图件参数和渲染检查，不能据此声明所有视觉布局通过。图件可读性、打印与真实材料走查在 03 按实际课时材料验收。
- 全年 Narrative 中仍有宏观、偏学术的表述；关键任务只做部分单元探查，不能据此证明全年每课可行。模型仍漏查过人工能找到的问题；独立审阅加程序检查不能替代数学教育评阅。

## 证据保存方式

每轮目录保留请求、实际 Context、知识、内容源、图件、阅读稿、检查、工具执行和用量；`drafts/` 保存各次实际提交的工具参数，便于核对保存失败与修订。原始详细流含私有模型消息及签名，仅保存在被忽略的 `work/year-live/` 中；仓库证据不复制它们或凭据。

[导出脚本](export_evidence.py) 可在仍保有本地工作记录时重跑；它校验用量及工具参数签名，不重新调用模型。三轮证据副本用于本次开发验证，不代表产品已实现内容历史 API。
