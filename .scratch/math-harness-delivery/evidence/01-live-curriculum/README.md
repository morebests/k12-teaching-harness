## 知识与 Context

真实服务为本地 Learning Commons browse，快照为 `lc/v1.11.0`。每次通过框架目录动态解析 CCSS Mathematics；目标 `8.F.B.4` 的图内 ID 与 CASE ID 分别记录，没有将二者互换。实际装配了 11 个支持组件、2 条前驱、8 条后继与 8 项数学实践；这些数量只说明本次目标，不证明全年范围完整。

`knowledge.json` 保留实体正文、源身份、关系方向、来源标记、分页与每次响应指纹。`context.json` 保留请求、可信身份、实际规则指纹、知识指纹、源快照、模型和包版本。模型只获得筛选后的知识及本次输入，没有目标课程读取工具；显式来源排除不能证明模型预训练记忆或未标明来源的文字完全无污染。

## 工程验证

- 原生服务 API：同事件重送与异正文冲突、同时重送、实际内容查询且不再生成、草稿标记、断流继续、取消、未实现能力、缺知识、越权、坏引用、当前内容变化导致旧检查失效、重入时保存原用量并停止。
- 知识边界：分页完整性、游标循环、关系方向、CASE／图身份分离和跨响应快照变化。
- 内容边界：公式、表格、实际图件、同目录写入、参数与 SVG 一致性及源稿变更失效。字面换行显示修复保留原 JSON，且不破坏 `\neq` 等 LaTeX 命令。
- 供应商适配：通过实际 Gemini 工具 Schema 转换复现六项依据丢失，改为显式类型后通过；可控模型测试不能替代上表的真实模型证据。

最终全量结果为 [24 项通过，11.50 秒](pytest.txt)，类型检查与 Ruff 通过，导出契约无漂移。补充的 LaTeX 多行公式反例曾失败，修复后单文件与最终全套均通过。完成后受控重启，原任务仍为 completed，run 数为 1、模型调用数仍为 25；此项不代表活动任务崩溃恢复。
