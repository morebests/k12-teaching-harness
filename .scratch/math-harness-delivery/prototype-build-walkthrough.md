# 全年教学工作区：构建与走查

日期：2026-09-15。用户授权：“shape 完成了就开始构建”。依据：[交互方案](teaching-workspace.shape.md)、[交互基准](prototype-baseline.md) 与 [交付规格](spec.md)。目标文件：[现行教学工作区](prototypes/teaching-workspace.prototype.html)。生产实现票保持原状态。

## 本轮落实

以课程内容组织位置：全年九单元概览 → 单元 5 的四课段与十八课规划 → 第 6–8 课实际材料样本。全年目录来自既有原创实验；课段、任务和材料为本轮合成交互样本，不是完成了独立课程设计或教学质量验证。沿用每课 50 分钟、160 常规课时加 20 弹性课时的演示条件。

顶部路径与宽窗口常驻、可折叠的课程树负责定位，窄窗口保留抽屉目录。课时内阅读入口区分概览、学生材料、教师指南、检查。输入、进度、待答、版本与条件在需要时展开。任务面板在足够宽的窗口位于内容旁；空间不足时位于内容上方，可收起继续阅读。不引入原开发走查台的场景菜单。

## 复看主线

1. 打开全年首页，进入“线性函数与情境建模”，查看完整课段／课时规划。进入课段 B，再打开第 7 课“把表、式与图连起来”，分别查看学生材料、教师指南与检查。
2. 在课时点“修改本课”，提交预填的时间调整需求；模拟结束后核对本课安排与版本。相邻课保持原来的讨论时间。历史版可读，修改需要回到当前版。
3. 在课段 B 的设计理由旁点“修改这一部分”，提交衔接需求。返回单元与全年，查看同一修改的影响摘要；受影响材料尚待真实复核。
4. 打开“条件与依据”，将每课改成 45 分钟。系统形成工作版本，原有 50 分钟材料会提示不一致，不会声称已自动改好。
5. 点“新建课程设计”体验条件输入和模拟进度；点“独立教学任务”体验不依赖全年方案的课时、适配、备课与理解度检查。

任务中的预填需求、明确动作和折叠的“演示文本”用于复现模拟路径。任意文字会保存原文，不能被静态页面理解。生产实现须由模型解释实际输入，不能移植这里的字符串匹配。

## 浏览器观察

通过本地 HTTP，在 Codex 浏览器完成 28 项行为观察，均符合预置样本的预期：

| 观察组 | 结果与边界 |
| --- | --- |
| 内容与位置 | 全年输入可进入执行并载入九单元；浏览其他内容不取消执行、不被结果强制拉回；目录可由 Escape 关闭并恢复焦点 |
| 局部与跨层修改 | 第 6 课讨论时间变化不影响第 7 课；课段衔接变化出现在单元与全年；历史内容保持；新条件不自动改写材料 |
| 创建 | 草稿包含原题与时间；只改稿不改已有材料且继续等待；改后生成与直接生成不重复请求同义确认；第 7 课生成结果保留对应材料身份 |
| 适配 | 审阅时可读整套样本；局部接受不升级整套；离开返回保留待答与接受范围；整套接受后结束 |
| 备课 | 正常路径先显示原题并等待教师尝试；开发 Agent 输入的教师回应样本进入讨论；明确结束形成便签 |
| 理解度检查 | 缺少焦点时等待；回应后显示开放题与验证范围；已有焦点的明确动作直接进入生成及两道验证的模拟过程 |
| 执行边界 | 停止后可续作；取消后不提供普通续作且没有迟到版本提交；自由文本不假装被理解 |

这些操作中的人类回应是开发 Agent 输入的合成样本，不是学校教师参与。备课的所有例外、并发故障、全部旧版本冲突及恢复机制未穷尽测试；以真实 Harness 规格和后续验证为准。

检查过 1440 × 900 桌面、766 × 934 实际窗口、390 × 844 窄屏，包含首页、课时材料与任务面板。窄屏材料图形、表格、正文可读，页面无整体横向溢出；控制台无警告或错误。内联 JavaScript 语法检查通过，Impeccable 单次静态检测无发现。

截图工具的长图拼接曾产生缩放和重复区块，未采用其结果。保存的是核对过的实际视口截图，含材料滚动位置，不声称取得完整长图证据。截图、逐项行为观察、检测及独立审阅记录位于仓库开发目录 `.impeccable/review/`；它们不随本地原型 HTTP 服务发布。

独立 Impeccable 审阅提出两项实质问题：独立任务的路径错误带有全年父级；窄屏图形标注过小。已分别修正任务身份路径及 SVG 响应式字号／标注位置，并补拍独立结果、桌面材料和双线比较图。原审阅者复核九张有效截图，将 F1、F2 均判为 resolved，修复复核结论为 `ship`。该结论限于这两项修复；不扩大为全面质量或所有行为验收。

## 限定与后续

## 设计制作边栏的后续修正

用户指出设计制作工作需要边栏，而非仅按阅读成品布局。已补入左侧课程树：宽窗口常驻并可收起，按当前单元／课段展开，显示课时规划与材料样本状态；独立任务仍不归属全年。窗口不足时保留抽屉目录，避免压缩正文。早先按需目录版的审阅结论属于历史证据；边栏修正另行完成六项浏览器观察：树中定位、收起保留输入入口、展开保留原文、抽屉跨课浏览保留原任务对象、Escape 关闭并恢复焦点、手机无整页横向溢出。宽屏／实际窗口／手机截图与独立审阅另存于 `.impeccable/review/sidebar-*`。

边栏版由新的独立审阅者检查五张有效截图及源代码，结论为 `ship`，没有本轮实质修复项；范围仍是既有 Operate 原型的这次扩展。设计记录保留既有视觉语汇，不把一次性原型提升为生产设计系统。
