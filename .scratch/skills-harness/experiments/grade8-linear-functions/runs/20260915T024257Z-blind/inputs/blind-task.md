# 独立读题检查 v0.1

这次任务只读取实际学生可见材料及其配套图形，不提供教师答案、生成过程或预期错误解释。

逐题独立解答，给出答案、必要条件及可以检查的简短推导。若有多个合理答案，给出范围和代表例；若材料缺少题目依赖的图、数据或说明，明确指出，不能猜测教师本意补齐。

检查题面能否确定要做的数学工作、数值和单位是否一致、图形是否满足文字条件，以及是否存在歧义。可以使用计算工具核验；计算记录只证明所计算的表达式。不要因为这是生成材料而预设它有错，也不要以文风代替数学判断。

输出英文 `independent-solutions.md`，用材料文件名和任务标识定位每道题，包含解答、发现及还不能判断的部分。针对实际出现的所有题目检查，覆盖情况单列，不按随机抽样宣称全部正确。完成后用 finish_candidate 交接；结论是模型独立读题结果，不能冒称专家评审或学生真实表现。
