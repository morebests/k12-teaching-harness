# 数学设计共同工作规范 v0.1

用途：两类原创设计任务共同读取的候选运行资源。课程与材料使用英语。以下研究条件用于本轮离线实验，不代表真实学校或学生的情况。

## 已给条件

- 设计美国 Grade 8 公共数学课程；标准始终是 CCSS Mathematics 内容标准和数学实践标准。使用随任务提供的完整标准资源，不另选框架。
- 全年共 180 个数学课时，每个 50 分钟。常规教学、练习和评价合计至多安排 160 个课时，另外 20 个保留为机动时间。单元数、顺序和各自时长由你设计，不要求等长。
- 一个班按 28 人的研究条件考虑，允许个人、同伴和小组工作。可用黑白打印、纸笔、直尺、方格纸、教师投影和普通计算器；不假定每个学生有联网设备。必需学习与评价在课内完成，课后练习可选。
- 教师应能直接使用交付的任务与材料，不需要自行补题、找缺失的图或重新解答全部题目才能开课。标出实际需提前准备的材料和工作；准备耗时的估计不是实测。
- 学生有前序年级课程经历的假设，但没有班级诊断、个人掌握度、残障诊断或已确认支持记录。不要把课程经历当作已掌握。设计进入检查和保留年级目标的通用支持；预测回应标为预测。

## 工作方法

**N1 先理解目标及其层级。** 阅读标准完整表述、必要子项和数学实践说明。全年、单元、课时各承担自己的范围；引用代码不是已经提供学习机会。分配教授、使用先备、为后续准备、复习和评价的不同职责，不要求每课覆盖全年或整条宽泛标准。

**N2 用知识辅助判断。** 允许使用数学推理和一般教学知识，不要求每个创意先检索。具体标准、知识组件和来源关系必须来自实际返回。`supports` 表示组件支持目标；`buildsTowards` 从基础指向后续支持联系，入边查基础、出边查后续；`relatesTo` 不表示先后。标准的层级树不规定课程顺序，图的支持联系也不等于每名学生都必须通过的严格先修。来源未提供的联系可以提出，但标为设计推断。

**N3 让设计理由接受实际工作检验。** Narrative 说明为何这样安排、从什么理解发展到什么理解、用哪些任务和回应辨别进展。不要只复述目录。关键数学任务可以在结构定稿前创作、试做，再据发现修订结构；不必遵循一次写完所有层级的固定顺序。

**N4 实际求解，检查数学含义。** 对交付的题目给出正确解答或适用的答案范围、必要解释和条件。检查单位、数域、变量、坐标刻度、表征对应、反例及歧义。数值计算或绘图工具可辅助验证，但不能代替解释；记录真正执行的检查，不把计划或自报当成工具结果。

**N5 保留学生的数学工作。** 任务应让学生作出有意义的选择、解释、比较、论证或联系表征，并提供为目标服务的练习。讨论写清交流什么、依据什么学生工作、教师如何推进；不只列活动名称。支持可以改变入口、表达或步骤负担，但须说明保留什么认知要求。概念理解、技能和应用按目标安排，不要求每道题承包全部作用。

**N6 检查必须能区分理解。** 学习检查与本次目标及已提供的学习机会对应。预判困难给出具体错误或不完整回应、可能原因、还需什么证据和教学应对；不要把一个错答确定解释为唯一成因。检查若声称排除某种错误方法，实际用该方法试答，确认它不会也得到正确结果。单次表现不能证明稳定掌握。

**N7 交付可用、相互一致的材料。** 真实题面、必要图表和作答空间在学生材料中出现；答案与教师观察指引分别提供。教师引导、学生任务、答案和观察使用可对应的任务标识及同一版本。学生有意使用的提示或示例可以保留，不能泄漏本次独立作答的教师答案。写作、计算和作图的空间与任务匹配；仅有 Markdown 内容时不得声称打印布局已经通过检查。

**N8 自主修复，按需要请人参与。** 沿给定约束继续设计、检查和局部修订，不为每个阶段重复请求批准。若无法同时满足明确目标和条件，给出具体冲突、已尝试的办法、取舍及受影响内容，请真实参与者决定。没有实际回应就保持待答，不能替对方确认。收到有效修改后保留对象与版本，重新检查受影响材料；不因局部修改无理由地重写全部内容。

**N9 如实结束和交接。** 返回本次产物、版本、采用依据、简明理由、实际检查、遗留问题及下一步。仅局部完成、等待回应、工具失败或预算耗尽时明确说明完成范围，保存可延续工作。内容检查、人类接受、真实课堂成效分别报告。上述编号用于引用要求，不要求为每条建立一个程序节点或额外模型调用。

## 可读取资源

初始资源是本文件、本次任务书、`../resources/ccss-grade8.json`、`../resources/ccss-practices.json` 和 `../resources/ccss-grade8-introduction.md`。两份 JSON 保留本地标准及实践原文；年级导言来自独立官方网页，不冒充本地节点字段。单元设计还须读取实际交接的上层设计。由执行环境提供按需读取标准、学习组件和支持联系的工具；不得假装已调用不存在的工具。读取失败或正文缺失时说明其对当前判断的影响，能以明确推断继续的工作继续，依赖来源事实的结论保持未验证。

工具说明与实际可用范围在运行时提供；本规范不等于已经实现了工具。使用工具取得的来源身份、内容与版本随工作保存，不读取运行环境未提供的其他课程参考。
