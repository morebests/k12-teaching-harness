# 任务 B：将蓝图中的线性函数单元落实为教学内容 v0.1

与 [共同工作规范](common.md) 和任务 A 的实际输出一起使用。**本文件不含虚构的上层蓝图；未收到实际版本时不能启动下层设计。**

## 接手时实际读取什么

读取运行记录指定的蓝图版本及其目标单元：目标与角色、完整标准及相关子项、Narrative、进入／离开条件、前后单元联系、时间预算、已有探查与真实决定。标准正文从随附 CCSS 资源按引用读取；有关 LC、进阶及邻接标准按需查询。

继承共同研究条件。没有实际学生作品时，进入条件与预判继续作为假设；不得把提供一份策略研究或一条知识关系视为学生证据。上层已给内容直接使用，不重问一遍。缺失可定位的交接内容时回取；无法回取就返回具体缺项，不凭主题重新编造一个蓝图。

## 先做何种范围

**首轮为关键课段试验。** 先提出整个单元的课段／课时骨架及目标—证据安排，再选一个承担关键理解发展、含真实前后衔接的连续三课展开。选择理由和位置由你从实际蓝图推出，不挑三节互不相关的展示课；不能为了满足“三课”把原本需更多时间的完整单元压缩进来。

这三课交付实际教师与学生材料、解法、练习和学习检查；其余课时明确仅到骨架。目标是检验上层交接能否落实，以及内容发现能否促成有效回修。输出必须标为**局部展开的单元候选**，不能称完整单元通过。

后续继续同一版本完成其余课时及单元评价，才可检查完整单元并冻结。扩大范围须由新的任务说明明确，不由这份首轮任务默认启动。单元内部分课时安排需跨越真实课时边界时，如实报告时间可行性。

## 实际教学工作

- **单元与课段**：解释目标如何发展、为何如此分组、关键表征的作用及转换；各课承担哪些具体工作，后课需要前课提供什么，哪里练习、检查和回访。无需每课重复全部单元标准。
- **课堂任务**：创作真实题面、图表和学生要做的工作；实际解答，核对合理答案及条件。将关键结构情形、数域和表征安排到适合它们的学习位置，不以难数字代替概念复杂度。
- **教师使用**：每课提供目标、先备、准备材料、时间安排、关键提问、可能的学生回应、观察线索与应对、讨论和收束的数学目的。关键回应包括正确、错误或不完整的具体实例，并标明为设计预测。
- **学生使用**：提供能直接做的任务及必要图形、数据、说明和合适作答空间；实际要求学生解释、比较或推理。教师答案与独立学习检查分开。只有文字说明要画什么而未提供必需图形，仍是未完成材料。
- **学习证据**：进入检查、课中观察、课末或课段检查分别回答什么；给出具体判断依据和下一步教学办法。当前只展开三课时，对完整单元的结束证据给出设计意图及待完成范围，不冒称已有全部题目。
- **支持与练习**：针对本任务可能的障碍提供具体入口、表达支持或拓展，说明维持的目标；当前没有个人诊断，不给学生贴标签。练习有目的地巩固或连接目标，不能只重复同一题型。

这些是需要完成的教学工作，不强制一条一个模型调用或固定课堂阶段名称。根据实际任务组织设计、求解、检查和修订。

## 怎样返回上层问题

下层任务暴露先备不足、目标分配矛盾、时间不可行或关键材料无法支撑预期时，给出具体题目／回应或时间依据，说明影响哪些课时与上层承诺。先尝试在已有目标和条件内修复；需要改变明确约束时提出可比较的取舍并等待真实决定。

返回实际更新的内容与版本、受影响的上层条目、需要重新检查的依据和仍可沿用的部分。不要只写“已同步蓝图”，也不要因一个任务变化从头重写全年课程。

## 本次交付与检查

交付单元骨架、连续三课的教师材料／学生材料／答案和观察依据、实际图表、采用来源、检查与修订记录。内容可先用 Markdown 和独立图形表达；打印、导出与视觉检查的真实结果另记。未渲染时可以评价内容，不能声称达到可直接打印的产物验收。

重点检查：三课是否兑现各自目标和前后联系；数学、解法、表征及材料一致性；学生是否真的获得所声明的推理和学习机会；证据解释是否合理；时间与资源是否可行；需要回修时是否以实际内容为据。三课通过不等于完整单元、教师备课能力或独立 CFU 技能已经通过。
