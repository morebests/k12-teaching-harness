# 教学要求的取用与评价约定 v0.1

日期：2026-09-15。用途：实验组织者与评阅者；**不整篇装入原创运行**。这是生成前写出的候选评价约定，未经过教师校准，没有任何模型成绩。原创可见要求在三份 [输入文件](inputs/common.md) 中；下表编号用于定位证据，不要求逐项增设流程节点或模型调用。

## 依据与各自负责的部分

- **CCSS** 决定内容与数学实践要求；本地完整输入及官方复核见 [采集审计](resources/ccss-input-audit.md)。模型提出的单元顺序不能冒充标准原文。
- **原 Skills** 是课时教学执行与材料质量的首选参考。固定子模块版本 `281eb8d41fe2837d911541c9bbb870b58add804c`，读取 [教案创建主流程](../../../../k12-teacher-skills/plugin/skills/k12-lesson-plan-creation/SKILL.md)、[数学参考](../../../../k12-teacher-skills/plugin/skills/k12-lesson-plan-creation/references/math.md)、[知识查询](../../../../k12-teacher-skills/plugin/skills/k12-lesson-plan-creation/references/learning-commons-kg.md)，以及 [shared.csv](../../../../k12-teacher-skills/evals/k12-lesson-plan-creation/rubrics/shared.csv) 的 33 条和 [math.csv](../../../../k12-teacher-skills/evals/k12-lesson-plan-creation/rubrics/math.csv) 的 6 条。下表穷尽这两份 CSV 的 ID，不代表穷尽五项能力的验收。详细流程分析继续保留。
- **课程层评价补充**：CCSS 写作团队的 [K–8 Publishers’ Criteria（2013）](https://achievethecore.org/content/upload/Math_Publishers_Criteria_K-8_Spring_2013_FINAL.pdf)，本轮核查 pp. 3–5、10–15：按标准重点组织内容、发展跨年级联系、兼顾理解／技能／应用，数学实践要落实在具体工作中；单项材料与全年课程的评价范围有区别。这里只取这些通用判断依据，未转录其中的课程例子或全文评分工具，也未验证所有条款。
- **本项目责任**：全年／单元／课时的双向交接、来源、版本、真实回应及停止规则，依据已有 [课程能力决定](../../issues/12-curriculum-design.md)、[执行决定](../../issues/03-execution-structure.md) 与 [HITL 决定](../../issues/07-hitl-protocol.md)。这些不是 LC 图自动给出的评分。
- **LVN** 可为具体支持策略补充研究证据；当前只有 Math 3–6 接口样本，尚不能作为八年级策略适用性的依据。此次没有把未经核查的 LVN 条目塞入输入，也没有接入 LC Evaluators 服务。来源存在不等于本轮必须调用它。

这里保留的是能由原 Skills 的一般执行目的、CCSS 或本项目明确责任支持的规则；未把 IM 的单元结构、具体顺序、任务、Narrative 或其派生设计要求改名后加入原创输入。原版 Skills 的完整执行基线另存，原创冻结后再比较。

## 生成前确定的评价对象与证据

对每项记录：**对象及版本、适用范围、通过／不通过／未评估／不适用、具体证据位置、理由与未解决问题**。不适用必须解释条件；没有材料或没有执行检查属于未评估或交付缺失，不能自动算通过。

| 编号与问题 | 应看到的通过证据 | 检查办法与限制 |
| --- | --- | --- |
| E1 目标完整且有承担位置吗？ | 全年 28 条内容标准及其 8 个子项无遗漏，八项实践有实际工作安排；单元和三课按分配职责检查 | 程序比对身份、遗漏及重复；评阅目标分配含义。父子项不是 36 个相互独立目标；蓝图覆盖不证明全年材料覆盖 |
| E2 学习进程可解释并被落实吗？ | Narrative、先备、表征和课时职责相符；关键三课的学生工作形成真实衔接 | 从实际任务反查上层承诺，查必要来源。其余课时只有骨架，不能判其材料质量通过 |
| E3 数学正确吗？ | 题面条件、图表、解答、答案范围、单位和说明一致；所称错误方法确有区分力 | 对本次实际交付题目逐题求解并核对图形；计算／反例检查辅助。存在实质错误时单列，不能由文风分数抵消 |
| E4 学生做了目标要求的数学吗？ | 学生实际解释、比较、建模或论证；练习有作用，表征和数域适用；支持保持目标 | 读学生材料，再对照教师意图与标准。预期讨论不等于学生确实参与 |
| E5 收集的回应能支持所做判断吗？ | 观察和检查有具体判据、合理答案、困难预测与应对，未教内容不会冒称已掌握 | 独立作答后再看答案和解释；对错误解释检查其他可能原因。模拟回应不证明学生掌握 |
| E6 材料兑现承诺并保持一致吗？ | 三课必需教师／学生／答案／观察内容齐全，任务和版本可对应，无泄题或陈旧文字 | 检查实际正文和图表，而非只查文件名。口头任务按其实际材料需要判断 |
| E7 学校条件下可使用吗？ | 时间核算、资源、准备工作和任务负担合理；真实呈现可读、可作答 | 内容估算、渲染走查、教师试用分别记证据。无渲染则版面未评估；无真实教师则使用效果未评估 |
| E8 依据可信且满足原创隔离吗？ | CCSS 框架、版本、来源和关系方向正确；推断／研究假设／学生证据分开；未取用禁止参考 | 查实际装配清单与工具返回。关键词扫描只能发现显式线索，不能独自证明无派生内容 |
| E9 修订保持上下层一致吗？ | 针对具体需求修改，相关上层／课时／材料更新，检查重跑于新版；无关内容可保留 | 对比修改前后实际材料及运行轨迹。只更新版本号或叙述“已同步”不通过 |
| E10 人类参与、工具与停止真实吗？ | 不伪造回应或工具成功；已有授权继续用，必要取舍等待真实人；失败／预算停止保留范围和状态 | 查真实请求、回应、工具记录与产物。用研究者输入可测机制，不能冒称教师课堂试用 |

E1–E10 是本项目补充的组织方式，不是新的外部评分服务。数学实质错误、关键目标没有实际学习机会、重要材料缺失、伪造来源或人类决定分别阻止对应完成声明；不汇成一个可被排版高分抵消的总分。可用上述证据说明局部架构可行，不能据一套样本宣布达到原 Skills 整体水平。

## 首轮怎样执行评价

1. 固定输入、模型设置、工具和预算后运行 A，再把实际蓝图版本交给 B。保存所有尝试，记录人工修补；不得只挑最好输出而隐藏失败。
2. 先做身份／覆盖／课时核算和产物一致性检查。对三课实际题目从学生可见材料独立读题、求解，再与教师答案比对；不继承生成对话或内部答案标签。相同模型新调用只能算信息分离的检查，不能称独立教育专家结论。
3. 按 E1–E8 逐项留下证据。没有数学教育评阅者时，模型评分只作初筛；记录分歧，不把模型一致当作专家校准。
4. 在候选内容基础上加一次跨层修订和一次局部支持变化。用普通需求表达，保留原话，不给“这是某某场景”的答案提示。支持变化使用明确标为模拟的证据；涉及真实接受或授权的回应必须由真实参与者提供。
5. 比较机制时先跑有充分规范与工具的简洁模型循环。发现具体缺口后才添加控制；对同输入、模型、工具、人类回应与预算比较改动前后，保留未用于调优的需求改写。首轮只证明出现了什么问题，不能用一轮结果推断稳定优劣。

每次运行记录实际模型 ID／配置、输入与输出指纹、知识快照、调用与工具次数、重试、耗时、可取得的 token／费用信息、待答与取消、实际修订及评价者。费用未取得就记未知，不根据输出长度编造。

## 后续完整单元与比较

完整原创单元完成并冻结后，才读取 IM 参考；按目标、先备、课时和资源匹配，版次选择及匿名方式遵守 [既有实验方案](../../assets/grade8-linear-functions-validation-design.md#完成后的比较与改进)。当前没有选取 IM 内容，也没有进行匿名评阅。

对照分别报告：全年蓝图的组织质量、完整单元的实际内容、固定上游 Skills 的教学执行与交互。原版 Skills 需要的资源及其固定数量规则另列原始成绩；本轮适配规则的成绩另列，不混为同一基线。参考影响后的改进版保留独立身份，不回写原创冻结版。课时创建中的学习检查不代替 CFU 技能完整验收，三课产出也不证明适配、教师备课等其余能力已实现。
