# 跨层修订试验 v0.1

以下是预先设定的模拟课程需求，用于检验修订机制，不来自真实学校，也不是新的学生学习证据。共同规范仍适用，读取所交接的实际蓝图、单元骨架和已展开课时版本。

课程负责人需要把目标单元的课时预算减少 20%（以当前单元课时乘 0.8 后向下取整，最少保留 1 课时），保持本单元核心目标和全年 CCSS 目标不变。全年常规课时上限和机动时间边界不变，不能以新增必做课后任务代替课内工作。

请依据实际任务与学习进程尝试修订：哪些工作可以合理合并、哪些数学工作需要保留、影响哪些前后课时和蓝图承诺。返回修订后的实际版本与变更说明，重新检查受影响的题目、解法、学生材料和观察依据。未展开的课时仍保持骨架状态，不能称所有材料已经重新验证。

若在这些条件下无法给出有教学依据的可行方案，说明具体冲突、已经尝试的办法和可比较的取舍，向真实参与者提出需要决定的问题并保持待答。不得替人确认放弃目标、增加必需资源或使用机动时间。若可以在既有约束内完成，就自主完成，不为了演示等待而强行提问。

产出保留原来不受影响的内容；引用父版本时须能定位具体文件与版本。修改蓝图或单元安排必须保存实际新内容，不能只在修改说明里声称“已同步”。
