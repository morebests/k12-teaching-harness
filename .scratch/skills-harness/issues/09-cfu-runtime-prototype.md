## Question

在理解度检查自身的执行结构和 HITL 设计明确后，用锁定版本的 LangGraph、持久化 checkpointer、固定模型返回和临时产物存储，验证候选结构是否满足已确定的执行要求。

本票验证 CFU 特有的候选结构，不决定四项 Skill 的实现顺序，也不把 CFU 设为其他 Skill 能力分析或实现的前提。

至少走查三类故障与恢复：

1. 保存焦点提议后暂停并关闭进程，以同一请求恢复，核对提议未变、明确改向直接成为焦点、重复或迟到回应没有误驱动执行。
2. 第一份文件成功或第二份文件成功但完成记录未保存时失败，恢复后形成一致的两份文件，并核对模型与文件操作是否按候选方案复用或重试。
3. 仅有一份文件、残留旧文件、内容被修改或沿用旧检查时，阻止提前读取验证资源或错误交付；修订后检查关联到实际材料。

据运行证据与人类走查决定是否接受该候选结构、需要怎样调整。原型只回答运行机制问题，不接真实学生数据，不以固定模型返回证明教学质量，不扩展其他 Skill 的教学流程。

## Comments

### Resolution：接受有限恢复与产物校验机制，教学质量和生产承载分别验证（2026-09-15）

已完成 [CFU 持久执行探针](../assets/cfu-durable-prototype-results.md)。使用锁定 LangGraph／SQLite checkpointer、实际临时数据库、固定模型工具往返和文件写入，13 项故障探针通过。用户对保存的具体焦点实际回答“采用上述变化率焦点”；回应记录后故意使进程退出，再从新进程恢复并重送同一事件，未重造提议、重复构建或重写文件。真实参与只记为原型评阅人的本次选择，不代表接受课程或课堂试用。

本票采用的实现依据：提议与等待分开保存；真实事件先持久记录，恢复使用已采纳动作；有价值的构建结果先保存，再执行可核对／复用的外部写入；完整材料与检查均绑定实际快照，交接前再次校验。第一份或第二份文件已写但图记录未提交时，恢复补齐清单且不重新调用固定模型；材料缺失、改写或检查属于旧版时，不能读取验证资源或误交接。已有有效焦点可跳过中断，明确改向不新增确认；旧提议回应和取消后的候选均被拦住。

同时取得 Agent Server dev 的真实 assistant／thread／run、流式输出及正常服务重启恢复证据；LangSmith SDK 实际发送到本地记录器，验证选定字段处理和 503 故障不阻断业务完成。这些证据分别不等于生产 PostgreSQL／Redis 故障恢复、全面认证隔离或 LangSmith 云平台接入。

固定内容经过原样文件回读及版本／读取顺序检查，未实现真实模型的两道教学验证；`runtime_probe_complete` 不表示 CFU 教学质量通过。任意自然语言理解、其他能力的人类参与、真实教师使用、破坏性代码升级和在途供应商请求取消另行验证。本票有限机制问题已回答，不继续扩成教学内容完善或生产系统；[调用接口](02-execution-interface.md) 继承这些事实并保持上述边界。

### 开始持久运行探针（2026-09-15）

用户在完整运行研究后要求继续执行。按本票既定范围，采用锁定依赖、独立临时数据库、固定内容返回和实际文件，验证持久等待、回应去重及采纳后的故障、材料写入和验证版本。先取得可复核的运行证据，不扩成生产服务或继续样例精修。固定测试事件与真实参与分别标记，后者只能在保存具体待答对象并收到真实输入后记录。

### 完整运行专项提供的实现依据（2026-09-15）

[LangGraph／Agent Server 官方研究](../assets/langgraph-agent-server-research.md) 与 [LangSmith 研究](../assets/langsmith-observability-evaluation-research.md) 已完成。开始本票时锁定依赖版本；优先核查可复用 Agent 循环与最少控制位置，明确中断节点重执行、回复保存到 resume 启动、外部写入和 checkpoint 的失败窗口。不要将现有单进程研究 CLI 直接当生产运行时。

依 [主执行候选](../assets/main-execution-design.md) 将请求身份、真实展示版本、回应／采纳动作及产物／检查关联到持久状态；Server 与 LangSmith 的 thread／run 各按其含义关联。原型可以使用固定或模拟事件检验程序语义，真实人类回应及其自然语言理解另取证；既有 Gemini 实验尚未验证这些路径。LangSmith 服务尚未接入的部分标明未验证，不以伪造 trace 或自动上传历史数据补齐。

本票继续只验证 CFU 相关运行顺序，不能以一次焦点恢复证明课程取舍、creation 草稿、适配接受及 prep 贡献均已实现。其共享恢复事实可供这些能力使用，教学特有行为留在各自验证中；此次仍未运行原型。

### HITL 前置已收敛（2026-09-14）

开始原型前读取 [HITL 决定](07-hitl-protocol.md) 及 [CFU 回应语义](../assets/hitl-design.md#理解度检查)。至少同时覆盖：正常提议后等待、已有本次有效焦点不重复等待、明确改向、旧版回应不误放行、重复事件不产生第二次生成、处理回应后下游失败仍恢复同一动作。既有焦点路径必须保留决定来源与范围，不能仅注入一个 approved=true。

固定模型和模拟教师事件须明示；它们只验证控制语义。由真实模型解释短回复、条件和改意的准确性进入质量票。已有双产物故障窗口与阶段资源检查继续保留，不因 HITL 规则完整而省略。
