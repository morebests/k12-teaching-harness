## Question

怎样依据本地 Learning Commons 的目标、组件和关系，以及学校日历、资源和学习者上下文，独立设计 Grade／Unit／Section／Lesson 的课程体系？

明确每层承担的目标范围、Narrative、学习进程、表征和任务安排、学习证据与完成条件。图中的学习进阶、课程依赖、对齐和本项目设计选择分别表达；不复制 IM 层级，不把图遍历或目录生成当成完整设计。

形成可以交给课时设计的具体依据，并明确课时试做发现问题时怎样回到上层修订。覆盖检查放在合适层级，不要求每课无条件包含关联标准的所有情形。学习支持变化和课程基线变化分别处理。

设计该能力自己的 HITL：哪些目标、节奏或资源取舍必须由真实参与者决定，审阅什么内容，如何关联版本并处理跨层影响。外部已授权的设计约束直接使用，不将每个模型步骤变成审批。

采用当前独立设计、后置 IM 内容对照的工作路线；明确原创版本、参考版本和改进版本的关系、可比条件及差距处理，不把离线对照称为课堂学习效果证明。

首个贯通验证以一个有年级位置和前后联系的数学单元为候选范围，包含真实课段、课时、任务、评测与一次跨层修订；具体主题随目标与验证需要选择。本票不实现数据本地化、外部 Learner Model 或生产服务。

### Resolution：课程设计的能力约定与双向交接（2026-09-14）

本票的产品取舍来自前述用户交流：独立数学课程体系是核心能力，使用已本地化的 LC，保留 Skills 的流程与质量参考，按学科和能力分别设计，并在既有授权下继续推进。以下收敛这些要求对应的能力约定；不把本轮技术分析记为用户逐项确认，也不声称已经验证生成效果。

1. **按明确范围设计四层课程。** 输入包含目标框架、年级／课程范围、学校约束、适用学习者证据、现有课程版本和本次决定。Grade 承担范围与衔接，Unit 承担核心进程与结束证据，Section 承担理解转变与任务推进，Lesson 承担具体学生数学工作。Narrative 解释这些选择，并与实际任务和证据关联。只设计一个单元时，不冒充完成了全年课程。
2. **知识依据与设计选择分开。** 保留标准、LC、关系类型／方向／来源及版本；按实际任务采用学习支持联系，不将图邻居或出版者依赖直接当作自有课程顺序。没有真实学习证据时，进入条件与预期困难标为假设；生成的学生回应不回写为 Learner Model 事实。
3. **采用可往返的课程—课时交接。** 交接同时给出必须保持的目标、关键内容及授权，和下层可创作的空间；返回实际内容、检查与有具体反例的修订发现。完整约定见 [双向交接分析](../assets/curriculum-design-capability.md#课程与课时的双向交接)。关键理解转变先落实为实际任务并试做，再据发现回修进程、展开其余课时，作为执行设计的起点；不能用代表任务通过替代完整单元检查。具体循环和停止机制由执行结构票决定。
4. **分别衔接四项既有能力。** 课时创建延续其任务／草稿／同源材料流程；适配使用实际原课与目标并落实有依据的支持；备课保留教师亲做、原课阶段与真实讨论；CFU 保留焦点选择、诊断依据、实际产物和验证。它们可以按需调用，完成条件不统一。课程覆盖按约定层级分配，适配须同时知道完整标准、本课职责及其他目标的承载位置；此处与上游全标准覆盖的差异明确记入比较，不能伪称逐字保真。
5. **修订与人类参与围绕实际对象。** 课时内可修复的问题局部处理；目标、先备、核心进程或资源不可行的问题回到受影响上层。超出授权的目标／节奏／资源取舍才提交具体方案与代价；既有有效决定直接使用。真实回应、任务和检查关联版本，旧回应不得自动批准新内容。个体支持与课程基线分别修订；最终发布治理由外部负责。
6. **交付与验证范围一致。** 蓝图可审阅、所请求单元的材料可用、整年完成分别声明。可教学单元需要实际课段、课时、材料、资源与评测，并检查数学正确、学习机会、证据与目标对应、跨层一致和学校可实施性。首轮以有年级位置及前后联系的数学单元贯通，并注入一次跨层改动；具体主题和样本在质量验证票结合风险选择，不以本次几何静态例子锁定实现学段。
7. **两个比较基线分别保留。** 既有四项能力按固定 Skills 的真实流程、产物和交互比较；原创课程固定 A 后再与可比 IM 内容 R 对照，形成有修订理由的 B。比较条件、改动与未采用规则如实记录，内容评分不能证明课堂成效。

本轮新增 [阶段 Context 与模型工作](../assets/context-and-llm-design.md#课程到课时的阶段输入与模型工作) 和 [八项纸面反例](../assets/curriculum-design-capability.md#交接与修订的纸面反例审查)，复核三项下游 Skill 的源码交接要求，并补回适配资源完备与 CFU 图形说明保留数学工作的两项细节。四项原详细分析继续保留。

**验证程度：** 已有官方资料研究、实际本地图只读样本与本轮源码／静态设计审查。未执行课程生成、模型评测、材料渲染、状态机或课堂验证；本票解决的是能力与教学交接决定。
