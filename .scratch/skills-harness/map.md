# 课程与教学设计 Harness 架构地图

Labels: wayfinder:map

## Destination

明确如何构建独立的课程与教学设计 Harness，首先面向数学，覆盖课程体系设计及课时、适配、备课和理解度检查，形成可验证的能力、执行流程、HITL 和后端架构结论。
项目目标、实施路线、设计与协作原则及外部边界统一见 [README](../../README.md)。本地图记录当前规划状态与决定；本轮架构规划已于 2026-09-15 收敛，交接入口为 [架构与可行性结论](assets/architecture-conclusion.md)；仓库最终交付目标仍是可运行的 Harness。

## Decisions so far

- [课程体系与教学能力的范围和质量基线是什么](issues/01-capability-contract.md)：独立课程体系设计纳入核心；数学优先，IM／Skills 为可取舍参考，本地 KG 由外部提供；具体设计和实现验证继续推进。
- [LangGraph 如何承载理解度检查的暂停恢复与文件验证顺序](issues/08-cfu-runtime-research.md)：已有局部框架文档事实；仅供后续执行设计参考，不表示采用该 Skill 的全部流程或已确定完整架构。
- [课程体系设计如何形成可教、可检验的学习进程](issues/12-curriculum-design.md)：收敛四层责任、课程与课时双向交接、修订及交付判据；具体执行状态与效果验证继续由后续决策处理。
- [IM 方法论与本地知识研究有哪些应进入 Harness 设计](issues/13-reference-research-transfer.md)：补强具体数学教学机制与学段差异，固化知识消费语义及证据基线，已接入相关设计和验证入口。
- [课程与教学设计的执行流程和状态如何设计](issues/03-execution-structure.md)：采用各能力自己的流程与有界模型循环；从交互到实现克制设计，充分利用模型推理与内置知识，先验证简洁实现再按缺口扩展。Context、真实参与、修订与必要运行边界继续保留，效果尚待验证。
- [课程与教学设计中的人类参与、暂停和恢复如何设计](issues/07-hitl-protocol.md)：分别确定五项能力的回应与结束、已有决定和复合指令、版本适用与多人冲突；接口及两项原型可据此展开，运行与质量尚未验证。
- [LangChain、LangGraph、Agent Server 与 LangSmith 如何共同承载教学 Harness](issues/11-agent-server-stack-research.md)：完成官方运行、部署与观察评测研究，明确框架能力及教学、产物和人类决定的应用责任；后续有限探针另有证据，生产部署及平台评测仍待验证。
- [理解度检查的候选执行结构能否可靠暂停恢复并验证实际产物](issues/09-cfu-runtime-prototype.md)：真实原型回应与 13 项固定事件探针验证有限持久恢复、双材料和版本控制；另有 Agent Server dev 重启及 LangSmith SDK 本地发送证据，不代表教学质量或生产部署通过。
- [调用方如何输入设计任务、参与交互并取得结果](issues/02-execution-interface.md)：采用少量任务级操作，分开回应接收／采纳／续作与有范围的交付；五项教学语义独立，生产调度和正式传输规格仍需实现验证。
- [模型、本地图查询和产物工具如何支撑教学设计](issues/04-runtime-adapters.md)：复用原生模型循环，以实际资源装配、本地 browse 语义、版本化材料和最终产物检查承载教学；具体模型和生产合并仍需验收。
- [如何验证独立课程与教学设计的质量和可靠性](issues/05-capability-validation.md)：收敛完整单元、各 Skills 与冻结后 IM 的分开评价路线及交付门槛；当前质量未通过项保留，方法明确不等于质量达标。
- [课程跨层修订、Context 与检查失效能否被清楚表达和执行](issues/14-curriculum-state-prototype.md)：有限页面和逻辑证据已吸收至调用设计；保留原型反例，不采用场景菜单或硬编码教学判断，停止扩张走查台。
- [采用哪套可验证的课程与教学设计 Harness 架构](issues/06-architecture-conclusion.md)：数学优先、任务级调用与各能力模型循环，复用 LangChain／LangGraph／Agent Server／LangSmith；架构可进入规格，完整质量与生产门槛按证据路线实施。

## Not yet specified

本轮架构目的下没有尚未分配的决定。正式 Schema、存储提交、运行资源及验收实现进入规格；完整单元、跨模型质量和生产验证已有 [明确路线](assets/validation-and-release-route.md)，未执行不等于已通过。

## Out of scope

- Web 产品界面、身份权限、学校业务流程及最终发布治理平台建设。
- 学习过程证据采集、Learner Model 构建更新及全系统归因分析；本仓库返回必要设计与执行证据。
- Learning Commons 数据本地化和远程访问开通。此前 [KG 后端接入研究](issues/10-learning-commons-integration-research.md) 保留历史结论，已不再作为当前架构前置条件。
- 以复制 IM 或原 Skills 全部形式作为产品目标，或重新判断是否需要建设 Harness。
- 生产代码交付及实际学校学习效果研究；本轮不把离线内容对照宣称为课堂成效。
- 首个数学范围之外的多年级完整质量、其他学科专属实现及广泛模型效果比较；保留后续产品目标，由对应范围另行展开，不将八年级证据外推。
