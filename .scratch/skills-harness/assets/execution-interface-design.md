# 教学 Harness 的最小调用接口

日期：2026-09-15。所属决定：[调用方如何输入设计任务、参与交互并取得结果](../issues/02-execution-interface.md)。本文是调用语义与接口设计；正式字段、传输协议、框架映射和运行结果尚未确定，不是已实现的 SDK。

遵守 [README](../../../README.md) 的克制设计与模型能力优先原则，承接 [执行结构](execution-structure-design.md)、[HITL 语义](hitl-design.md)、[课程双向交接](curriculum-design-capability.md#课程与课时的双向交接)、[Context 设计](context-and-llm-design.md) 和 [知识使用约定](../../../docs/references/knowledge-consumption-contract.md)。原 Skills 的详细流程和源码继续通过 [索引](index.md) 读取。

## 调用方只需掌握什么

调用方表达要完成的教学工作，提供已有内容及其使用范围；Harness 使用模型、内置知识、适用规则和工具，取得依据、形成设计、检查和修订。调用方不负责排列图查询、试做、渲染和检查节点。

共同承载只保留四类操作。下列名称说明职责，不锁定四个 HTTP 路由，也不要求自建与 Agent Server 重复的任务系统。

| 操作 | 调用方提供什么 | Harness 返回什么 |
| --- | --- | --- |
| 启动工作 | 自然语言目标、已有材料／上下文，必要的目标对象，以及可信调用环境 | 可继续访问的工作标识和接收结果；进入教学工作后可返回进度、具体待答或产物 |
| 提交输入 | 所属工作、原始文字／选项／附件；回应某请求时带该请求标识，修改时带所指对象 | 输入接收及采用情况、仍需解决的问题；实际后续工作沿已有内容继续 |
| 读取工作 | 工作标识；需要时定位具体结果、请求或证据 | 当前工作情况、待答内容、实际结果及其版本、检查与执行证据入口 |
| 取消工作 | 工作标识及可信取消请求 | 取消处理情况、已保存结果及仍在收尾的工作；不能把收到请求当作所有在途调用已立即终止 |

读取是基本能力；流式进度是同一工作信息的增量呈现，不改变其完成条件。掉线后能重新取得当前情况和已发生的必要事件；流式游标、存储和取消的具体保证由 [完整运行时专项](../issues/11-agent-server-stack-research.md) 核查。

## 启动输入保持小而充分

入口推荐自然语言目标加已有上下文，允许调用方明确限定能力。能力提示可来自 Web 中已选的功能，也可由 Harness 理解需求后确定；该入口取舍在决策票记录。首阶段仅执行已支持的数学能力，不因能识别其他学科就宣称已支持它们。

| 输入 | 谁提供、什么时候需要 |
| --- | --- |
| 本次需求 | 教师／课程负责人或调用产品提供，例如“设计一个分数除法单元”或“按原目标压缩一课”。事实足够时直接推进 |
| 已有对象与材料 | 修改、适配、备课时提供所选对象或可读取材料。新建课程不需要先交一份已有课程；标题不能代替实际原课 |
| 已有教学上下文 | 产品提供已掌握的年级、目标、学校条件、相关学习者状态和有效决定；既可内联内容，也可传可解析的版本引用，不要求重复录入 |
| 可信调用环境 | 产品后端提供身份、资源使用和修改范围、运行预算等。教师不填写内部权限对象；凭据不进入模型消息 |
| 可选的能力／交付限定 | 调用方可明确“只备课，不改原课”“只看课程方案”或“直接生成材料”。自然语言已经明确时，不强迫再填一组同义字段 |

引用在实际使用时解析为可定位的内容与版本，保存本次采用依据。已明确版本不能静默换成最新；尚未给出版本的输入由读取结果确定并记录。只读取当前工作所需内容，后续可按需回取；不要求启动前把全部 KG、课程和 Learner Model 展开。

目标拆解、知识路径、任务安排、检查范围和自然语言意图解释由 Harness 形成。它们可以随工作记录返回，但不是调用方开始使用时必须提前填好的表单。结构化条件与原话冲突时，结合来源、时间和明确修改判断；仍影响目标或授权的歧义才提出具体问题。

不把能力识别当成无限授权。用户要求准备一节已有课时，模型发现问题可以指出；实际改课仍需要相应请求与权限。新课中需要支持或分层内容，沿创建能力完成，不自动叠加独立适配协作。来源：[creation 路由](../../../k12-teacher-skills/plugin/skills/k12-lesson-plan-creation/SKILL.md)、[prep 职责](../../../k12-teacher-skills/plugin/skills/k12-lesson-prep/SKILL.md)。

## 输出同时表达工作、交互与实际内容

最小返回内容要能回答五个问题；它们不必成为五个独立文档或服务。

| 调用方需要知道 | 应返回的内容 |
| --- | --- |
| 现在进行到哪里 | 排队／计算／等待／本轮结束等实际情况，简短教学进度与结束原因。没有可靠工作量依据时不伪造完成百分比 |
| 是否需要人参与 | 具体待答请求、实际任务或草稿、对象版本及回应方式；不存在请求时不生成泛化“请批准继续” |
| 已经得到了什么 | 实际产物或可读取引用、内容版本、受众、适用课程／班级／个人范围，以及草稿、已检查材料或部分成果的真实身份 |
| 哪些要求仍未满足 | 当前检查发现、缺失材料、尚未发生的参与及未完成范围；材料已经存在不等于全部教学工作完成 |
| 依据能否追查 | 采用的输入和来源、重要设计理由、检查范围与版本、修订及人类输入记录的可访问入口 |

重要区别在默认返回中直接可见：例如“材料已生成，等待本套审阅”“本轮因预算停止，单元尚未完成”。详细过程按需读取，教师不必浏览完整工具日志。证据记录保留简明理由和实际结果，不要求模型输出隐藏思维链。

产物需要可供后续能力实际读取：课时任务、解法、表征、Narrative 和材料等不能只返回标题或封面摘要。课程与材料的具体结构由对应能力定义，载体由 [模型和产物工具](../issues/04-runtime-adapters.md) 收敛；这里不建立包罗五项能力的统一内容 schema。

**可展示内容与内部工作分开取得。** 进度流只包含允许向本次受众展示的内容；教师备课的内部试做、CFU 的答案映射和未到展示时点的题目，不能借 token 流或调试数据提前展示。权限和信息隔离在执行端成立，不能只期待 Web 前端隐藏字段。内部检查／追溯接口的访问也沿其用途限制。

## 人类输入沿原对象继续

待答请求至少能定位真实问题、所属工作、展示内容及版本、所需参与和后续用途。按问题需要提供短选项、自然语言和附件入口；教师亲做可以提交文字、图像或可读取作品，不统一为“同意／不同意”。多项相关缺失可合并一轮提出，具体问法沿各能力设计。

调用产品为一次真实提交提供稳定身份，网络重传沿用该身份；Harness 保留原话、所指请求和展示对象，并返回是否已接收、采纳或仍需处理。相同提交重传不再生成一份材料，相同身份携带不同内容不能静默覆盖；新的改意有新的提交身份。接收成功不等于授权有效或工作已经完成。

自由文本由模型结合原问题、实际对象及既有决定解释；程序核对来源、适用范围与当前工作，再执行相应动作。原话仍保留，解释不覆盖它。已明确“按这些修改直接生成”时沿范围继续；只有修改意见时遵循原协作路径。外部已给决定直接使用，不重演一次确认。

输入可以在等待期间或执行期间到达，也可以明确引用已完成的成果提出后续修改。后续工作沿已保存内容建立修订；原完成／取消事实和历史交付保持。已取消工作不会因旧回复到达自动复活，明确的新请求可引用保留内容继续；预算沿有效配置处理。应用工作与框架各次运行的映射留给运行时专项。

多人规则由外部提供，Harness 保存相关原始事件并遵守决定范围；缺规则或有实质冲突时返回具体问题。这里不自建学校审批流程，也不因为接口简单就忽略后到的不同有效意见。

## 用同一承载保留五项能力

以下不是五个状态机的定义，而是核对简单接口是否能携带各项工作的不同内容。

| 能力 | 入口及返回中不能丢失的内容 |
| --- | --- |
| 课程体系设计 | 可以从目标新建，返回进程、各层职责、Narrative、真实任务与证据安排；仅请求蓝图则按蓝图范围结束。跨层回修由 Harness 组织，授权外取舍才成为人类待答。详见 [课程交接](curriculum-design-capability.md#课程与课时的双向交接) |
| 课时与材料设计 | 直接使用已定整套／草稿路径；草稿有实际任务及先备条件，后续沿其内容生成。正常交付后可结束，不引入适配的满意等待。详见 [创建流程](lesson-creation-execution-design.md) |
| 教学适配 | 使用实际原课和本次目标，个人／班级支持带适用范围。正常协作中，材料可读取而整套满意仍待回应；明确只生成供外部后审则按该范围结束。详见 [适配语义](hitl-design.md#教学适配) |
| 教师备课 | 提供原任务，接收并使用教师真实贡献；保留先尝试、内容解释、先示范、拒答、短时及结束的适用差异。便签与讨论不能冒充改课或学生实际表现。详见 [备课语义](hitl-design.md#教师备课) |
| 理解度检查 | 可独立按主题／标准启动，不强制已有完整教案；先取得本次有效焦点，材料构建及实物验证后再交付题目。详见 [CFU 详细流程](cfu-execution-design.md) |

共同承载不要求一个任务自动依次调用所有能力。课程生成会使用课时设计工作；是否追加适配、备课或 CFU 取决于本次目标，不能为了展示完整能力而增加用户未要求的协作。

## 两条可读的调用轨迹

下面都是接口设计示意，没有执行模型、图查询或服务器调用，也不固定首个实施主题。对象名是占位符，字段拼写不是正式协议。

**新建单元：**

```text
启动：
  需求：为六年级设计一个分数除法单元，共 8 课，每课 45 分钟。
        先给可审阅的进程方案和关键任务，不先生成全套学生材料。
  已有上下文：目标框架、年级课程位置、班级支持条件的可读取引用。
  可信环境：调用产品注入的访问与运行范围。

Harness：
  理解范围 → 取得适用规则与知识依据 → 设计并试做关键任务 → 回查。
  在给定目标和权限内自主选择具体行动，必要缺项才提问。

返回：
  本次方案已形成；有版本的 Narrative、课时职责、关键题目和设计依据。
  未生成全套学生材料，不宣称可教学单元已完成。

后续输入：
  针对该版本：第二课先加强图示和算式的联系，其余按这个方案展开材料。
  Harness 沿实际方案修订和展开，核对原范围与新指令，不从主题重新造单元。
```

本例只要求先交方案，并没有要求 Harness 持续等待一项正式审批。返回方案即可按本次范围结束；如果原请求明确要求“先审后继续”，则返回具体待答并保留继续位置。两个含义不能从“先”字机械合并，已有上下文清楚时直接使用。

**修改已有内容：**

```text
启动或后续输入：
  所指对象：已采用的单元版本。
  需求：在原目标不变的情况下压缩一课，改好直接给材料。

Harness：
  读取现有任务、评测、Narrative 及依赖；自主合并或调整并检查。
  可在授权内完成 → 返回新版本、改动与检查依据。
  确需改变目标或额外资源 → 返回具体冲突、真实候选及其代价。

回应具体请求：
  所指请求及展示版本；原话或方案选择，由真实参与者提交。
  Harness 核对、采用并继续；不要求调用方告诉它下一步该执行哪个图节点。
```

这条轨迹不预设模型先删掉唯一学习机会；成功标准是实际目标、任务与条件是否兑现，而不是复现 [旧原型](curriculum-state-prototype-notes.md) 的九个按钮。

## 本轮采用范围与后续验证

本轮收敛调用方可见的工作语义。HTTP／SDK 字段、Agent Server threads／runs 的对应、存储事务、流式重连、运行中输入调度和产物载体，分别进入 [完整运行时](../issues/11-agent-server-stack-research.md) 与 [模型和工具](../issues/04-runtime-adapters.md)。先复用已有运行承载，只有教学领域确有责任才补充实现。

[质量验证](../issues/05-capability-validation.md) 先让简洁模型循环通过这个调用面完成有实际内容的工作，再按观察到的问题增加控制。初步核对：调用方能否只给目标及已有上下文启动；明确输入是否被重复追问；中途修改是否沿原内容；必要教师贡献与材料展示时点是否保持；停止后能否取得真实成果与未完成范围。评实际内容和有目的的过程，不评原型动作顺序。

目前只有资料与接口纸面审查。接口能表达这些情况，不证明模型能理解全部自然语言、产物质量达标或服务器能可靠恢复；不据本报告宣布 Harness 已可运行。
