## 八项值得进入后续设计的内容

### 1. 先说明活动的数学目的，再选择教学动作

**官方事实：**IM 为活动区分概念、表征、形式化、误区辨析、熟练和应用等目的；教学动作随目标选择。[课时说明][lesson]、[教学与备课][pbl]
**长文推论（§4.1、§5.2）：**不能把所有活动都压成“先探索后讲解”；活动目的相同、换数重复的题也不一定构成学习进展。
**本项目建议：**课程到课时交接增加“本任务带来的理解变化”和“学生必须亲自完成的数学工作”，由模型据此选择说明、示例、练习、讨论或建模。
Context 同时带入任务先备、已做过的数学工作及支持条件；“探索”“熟练”等只是设计说明，不预设永久枚举或一类目的对应一个图节点。
新增价值在于将现有“真实任务”的验收具体化：审查动作是否实现所声明目的；若标准步骤已给出，仍能完成的只剩模仿，就不能宣称学生自行概括了该步骤。
外部研究亦不支持把所有明确指导排除：IES/WWC 建议交替使用已解示例和独立解题，指南对该建议标为中等证据。[学习与记忆指南][wwc]

### 2. 表征需要保存其数学含义和学习历史

**官方事实：**IM 的表征既帮助理解，也用于解题；选择与次序取决于目标和进程，同一种图在后续年级可以承担更抽象的作用。[关键结构][structures]
**长文推论（§4.5）：**图的数量不能证明质量；完成了关键对应关系的图，也可能提前替学生做掉目标工作。
**本项目建议：**核心表征随任务保存“各部分代表什么、学生要建立哪种对应、使用范围与局限、何时已引入、后续怎样复用”。
模型改变单位、数域、比例尺或图中对象含义时，回查前后任务、解法、解释和评测；仅保持 `number_line` 或 `diagram` 类型不证明语义连续。
相比现有表征与跨层检查，这补上了可执行的回查对象；LC 图提供知识关系，不能替代自有课程对表征的实际使用记录。

### 3. 讨论预案与真实课堂响应必须分开

**官方事实：**5 Practices 包含预判、监测、选择、排序和连接；材料承担部分预判及排序、连接准备，课堂仍需观察学生工作。[课时说明][lesson]
**长文推论（§4.7）：**计划不能提前指定实际学生作品，也不能把预期策略记成现场发生过的策略。
**本项目建议：**教案模型生成“可能的作品特征 → 要辨认的数学差别 → 比较次序及连接问题”，明确它是预案；教师备课可用实际任务演练。
外部系统以后提供真实作品与教师判断时，Harness 才据该输入提出调整；本仓库不承担课堂采集，也不以模型模拟代替真实教师或同伴。
这补充既有 HITL 的教学语义：内容审阅确认的是预案，教师亲做证明的是备课行动，课堂选择证明的是对实际作品的决定，三者不能互相替代。
上游 [备课 Skill](../../../k12-teacher-skills/plugin/skills/k12-lesson-prep/SKILL.md) 的原任务亲做、教师先答和短轮讨论继续保留；不能借 IM 研究将其扩大成强制填写课堂诊断表。

### 4. 支持不能都套用“逐题撤除”

**官方事实：**IM 分别讨论减少障碍、辅助技术、表达方式及课时支持；支持服务于有要求的数学工作。[可访问性说明][access]
**长文推论（§4.8）：**普遍可访问性、持续 accommodation／辅助技术、临时教学支架、扩展属于不同责任；只对临时支架讨论适用的减弱条件。
**本项目建议：**适配 Context 保留支持来源、对象、目的和条件；不能由模型仅凭答对题或课次增加就删除持续支持。
质量检查同时看目标是否保持、学生是否仍承担关键数学工作；增加表格、句框和提示的数量不代表更好适配。
这是对原 [数学适配流程](execution-contract-draft.md#数学适配必须实际完成的教学工作) 中固定支架递减规则的重要适用性补充；原条款及其效果基线保留，产品是否替换须在对应决策中说明并验证。
学校提供的支持安排属于输入约束；本报告不判断法律义务，也不由 Harness 自行诊断或取消安排。

### 5. 练习进程要表达时间和用途，不能只附一组题

**官方事实：**IM 的课后练习兼有本课及更早内容，教师可选择布置范围和用途。[课时说明][lesson]
**长文推论（§5.6、§9.2）：**跨时间出现只证明安排了回访；是否发生独立检索，还取决于实际作答、答案揭示和帮助条件。
**本项目建议：**单元设计明确核心目标何时首次学习、练习、回访和迁移，保留删课或改日历后受影响的机会；不硬编码统一题量或间隔。
Harness 交付练习安排、理由和预期证据条件；实际布置和作答由外部系统提供，未收到这些事实时不宣称学生完成或产生保持效果。
这补足现有“复习与迁移”要求中的时间语义。IES/WWC 将间隔、主动检索作为不同建议说明，不能把二者合并成一条生成提示。[学习与记忆指南][wwc]

### 6. 形成性检查的响应规则必须关联用途和证据范围

**官方事实：**Grade 8 的 More Chances、Points to Emphasize、Press Pause 是题目附带的教学指导，结合多数学生的表现决定全班后续；它们不是个人诊断标签。[中学评测指导][assessment]
**长文推论（§4.9）：**题目、实际回应、帮助条件与解释要连起来；单题错误本身不能证明长期状态。
**本项目建议：**设计 CFU 时同时保存要区分的理解、可观察表现、竞争解释及下一步建议的适用条件；不把选择某个选项直接写成 Learner Model 事实。
对“后续会再遇到”的建议，必须能回取后续真实任务；若课表修订删掉那次机会，则该建议需要重查。
这是现有 [CFU 错误映射与文件验证](cfu-execution-design.md) 的课程层补充，不能取代其实际求解、隔离读题、错误推理验算和材料回读。
同一题可以用于不同教学目的；本报告没有采纳外部项目的独立 Assessment 聚合、QTI 版本或逐 owner 人工提交规则。

### 7. 互动协议有不同的信息、循环与材料寿命

**官方事实：**MLR4 隔离两位参与者的信息；MLR1 有初稿和修订；MLR2 的集体语言材料跨课时延续；MLR8 是可组合的教师动作。[课时说明][lesson]
**长文推论（§5.3）：**同叫 routine，也不能共用一份固定顺序；学生稿、小组作品和全班材料不能混成个体能力证据。
**本项目建议：**选用某互动方式时，按其实际机制描述角色、可见信息、揭示条件、可重复步骤、需要保留的作品和教师动作；只装配该任务适用的协议。
若教学需要真实同伴，单人 Web 条件下应提出另一项有理由的设计或说明需求未满足，不让 LLM 假扮同伴来伪造原活动已经完成。
这扩展现有“教师／学生／盲答者可见范围”：某些活动还要求学生之间的信息隔离，某些材料需要跨课时延续。是否建设独立协议库由后续真实复用需求决定。
Harness 当前首先设计并交付这些教学材料及要求；只有产品请求且提供运行条件时，才谈承载现场互动，不借参考研究扩建完整课堂平台。

### 8. 教师可实施性应通过准备工作来检查

**官方事实：**IM 明确高质量材料仍需教师备课，包括理解进程、预判、提问、支持、节奏和器材准备。[教学与备课][pbl]
**长文推论（§4.10）：**Narrative 的作用需要经过教师理解及实际实施，材料完整不等于教师已经准备好。
**本项目建议：**让未参与生成的读者据材料定位关键数学、亲做任务、解释一次取舍、找到所需资源，并指出哪些地方可以调整；把障碍作为可审阅发现返回。
这给现有“学校可实施”检查增加了任务依据。程序能核对资源与时长清单，模型可以发现问题，实际教师试用才提供教师准备负担的证据。
不把所有教师准备都改成审批；HITL 保留具体教学目的、实际已有授权和各 Skill 自身结束方式。

## 数学内部差异：补查的反例与采用范围

长文明确没有完成跨学段对照。本次补查已经足以反驳“Grade 8 的固定形式可用于全部数学”，尚不足以给出完整 K–12 教学分类。

| 本次核对的官方事实 | 对本项目的实际影响 |
| --- | --- |
| K 多数课、Grade 1 部分课没有独立 Cool-down，改用课段观察清单；Grade 2–5 有另种 Checkpoint 安排。[小学评测指导][elementary-assessment] | 课程证据计划必须容纳操作、口述及跨课时观察；不能把独立书面退出题当每课必填，也不能因缺该文件判课程不完整 |
| K／Grade 1 的 centers 嵌入课时；Grade 2 的 center day 可选；Grade 3–5 多作额外资源。[小学关键结构][elementary-structures] | 练习载体、材料复用、选择空间和时间预算随阶段处理；不能将全部 centers 按单课独立练习生成 |
| K–5 的 Cool-down 响应采用 Next-Day Support、Prior-Unit Support，与 Grade 8 的三类指导不同。[小学评测指导][elementary-assessment] | 不能统一成三档状态；应先说明证据用途、后续课程和支持，再决定呈现方式 |
| IM 高中数字工具原则重视学生自主选用工具，和提供现成探索 applet 的方式有所区分。[全局组织原则][principles] | 计算／绘图／几何工具是否提供、何时提供及是否自动完成目标工作，要跟随数学目的，不能由“Web 产品”一律决定 |

即使同为一年级，图形属性解释与加减未知量问题的学生工作也不同。沿 [本地 LC 几何实测](learning-commons-integration.md#k2-几何的本地实测) 选择实际目标与关系，不能只用年级选择一个通用活动模板。
同一表征跨目标时也不天然相同：例如表示整体、单位、计数或变量关系，需要逐次核对含义。小学官方说明已经列出不同领域和年级的表征进程；本次只读正文，没有逐图审阅所有进阶图。[小学关键结构][elementary-structures]
后续应以“学段 × 数学目标／领域 × 活动目的 × 学习及实施条件”选取适用资源；这是一种检索与判断方法，不要求把四者做成固定笛卡尔积或新模块。

## 建议落点与下一步可检验工作

| 现有工作位置 | 建议纳入的具体内容 | 可证伪的静态案例／后续原型观察 |
| --- | --- | --- |
| [课程设计](curriculum-design-capability.md) | 活动作用、表征语义和使用史、跨时间练习与证据计划 | 删除唯一建立“单位整体”的任务后，后续分数题仍在：应指出实际断裂，不能只更新 Narrative |
| [Context 与 LLM](context-and-llm-design.md) | 当前目的、前次真实任务、支架类型、信息揭示规则、已有作品及来源版本 | 同一题的教师预案进入学生信息包，或 MLR4 私有数据泄露：应判定可见范围错误，而非提示学生忽略 |
| [执行结构](../issues/03-execution-structure.md) | 按教学目的组织模型动作；计划、实际工作、验证及受影响修订分别保留 | “引入概念”与“巩固熟练”两类任务不能靠复制同一提示及顺序宣称都满足；保留选择和检查依据 |
| [HITL](../issues/07-hitl-protocol.md) | 内容预案审阅、教师亲做、具体课程取舍分别处理 | 教师审过讨论预案，不应被登记成实际观察了某学生；教师明确不继续备课时仍能按原流程结束 |
| [质量验证](../issues/05-capability-validation.md) | 适用性反例、实际数学工作、材料／实施／学习／效果的证据层次 | 去掉 K 课不适用的书面退出题并补合适观察证据，应可接受；去掉全部证据不能通过 |

优先把这些案例并入既有单元贯通验证，不另立一个 IM 复制工程，也不在此确定首个数学主题。
对四项既有能力继续与固定上游流程作可比评测；新增课程能力检查真实跨层关系。IM 对照保持原创 A、参考 R、修订 B 的可追溯条件，避免将已见具体参考的产出称为未接触参考。
结构与引用错误可由明确程序规则检查；“表征是否合适”“讨论是否推进数学”“支架是否代做”需学科判断与明确理由，不能只凭字段存在或模型自评通过。

## 不直接迁移的内容与证据限制

- 不迁移外部仓库自己的 Workspace、Generation Target、Placement、QTI、发布状态及 LLM 写入限制；若未来接口确需对接，再以真实外部契约分析责任。
- 不将 IM 的四阶段、特定 routine、活动数、分钟数、固定分组或三类教学响应升格成全项目必需形式；重要参考流程仍保留并逐项评判。
- 不由本报告判断材料再利用权或复制完整官方材料；主研究另核查来源范围，本报告的引用只支撑所述教学事实。
- 未完成长文列出的全部教育论文再审、K–12 全部官方指南对照、所有课时和评测审计；IES/WWC 本次只核对公开建议与证据等级，不据此声明本 Harness 的生成结果有效。
- 没有课堂、模型和替代机制的效果证据。当前可以固化的是来源、适用性边界和待检验设计要求；“效果最好”“已超过 Skills”仍不能成立。
