# 数学图形与可视材料：从教学用途到可修订产物

日期：2026-09-15。状态：**后置讨论候选**。用户提出将图等非文字资料的生成单列，先形成意图、目的及形式建议，随后反复精细生成。本页评估这个方向，供 [调用接口](../issues/02-execution-interface.md)、[模型与产物工具](../issues/04-runtime-adapters.md) 和 [质量验证](../issues/05-capability-validation.md) 后续使用；不表示已经采用新的生产模块或完成实现。

**排期纠正：**用户随后指出不能因提出某项建议就立即把它当下一步。图形能力保留，其小型对照与精修暂不启动。先推进主执行方案、Context／内容交接和实现前运行架构；后续进入相应材料实现，或有证据表明此问题阻塞当前主线决定时，再展开本页候选。

项目目标仍以 [README](../../../README.md) 为准。本文处理已有课时与材料职责中的专业工作，不改变五项教学能力范围，不预设新增 Agent、服务或强制审阅步骤。首个实现对象建议为当前八年级实验所需的静态函数图、坐标网格及其标注；几何、数轴等按后续实际任务分别扩展。

## 为什么值得单列

这项划分有实际依据。当前实验中，算式正确而图上线段错误、遗漏题图、图例提前给答案、标注重叠分别出现；视觉评阅也曾误读正确网格。见 [实际质量裁定](../experiments/grade8-linear-functions/quality-review.md)。这些问题具有自己的内容、工具和检查要求，不能仅作为长篇教案末尾的排版工作处理。

上游已经提供两个重要起点：

- [数学规范](../../../k12-teacher-skills/plugin/skills/k12-lesson-plan-creation/references/math.md) 要求实际视觉支架，保留教师侧用途说明，并区分学生操作材料和会提前给出思路的教师参考。
- [输出规范](../../../k12-teacher-skills/plugin/skills/k12-lesson-plan-creation/references/output.md) 让共享内容保持同源，特殊形态的附件采用适合的格式；其现有文档渲染器说明不能绘制图片，主要列出表格、数轴等块。因此原流程值得保留，精确函数图及其持续修订需要补充实现。

建议将这项工作组织为**可独立调用和修订的数学可视材料模块**。课程、课时、适配和理解度检查可复用它，使用者只需提供教学请求、相关内容和当前版本；数学描述、绘制、版式检查及修订历史集中在模块内部。模块的价值来自这些具体职责，而非只包装一次“画图”调用。

教学用途仍由课程或课时设计负责。绘图发现问题时能带着具体证据返回修改题目、表征或上层安排；不能独立选择一个漂亮但改变学生工作要求的图。这个模块可以由现有模型循环调用，调用次数不等于模块数量，也不必为它新增常驻 Agent。

## 先表达用途，再逐步提高完成度

用户提出的顺序可作为默认工作方法，以下是信息逐渐完整的过程，不是每张图都必经的固定节点或教师表单。

| 当前工作 | 应形成什么 | 此时能支持什么判断 |
| --- | --- | --- |
| 课程／课时构思 | 教学用途说明：学生看图后要做什么；建议采用何种表征；为什么；关联哪项任务；哪些信息应给出或留给学生求出 | 判断是否需要这张图、形式是否合适；未生成的材料仍是待完成事项 |
| 关键任务试做 | 数学内容及粗略预览：数量／对象、关系、单位、定义域、刻度和必要标注；已有数据与模型新设计分别记录 | 判断题目是否可读、可解、具有原定思考要求；不需先精修全部版式 |
| 材料生成 | 可编辑的数学描述与绘制源、实际图、师生用途对应的版本，以及在当前载体中的预览 | 可以检查真实图形及材料，不再只有“此处配图”的占位说明 |
| 局部精修 | 在实际版本上按需求修改；保存差异、受影响任务与对应检查 | 可多次改刻度、标签、留白、支持或呈现方式，复用未改变的工作 |
| 教学包集成 | 当前题面、图、答案、教师引导和使用位置一致，必要图件实际可取得 | 图件本身通过不等于整课通过；还要核对任务、受众与课堂条件 |

**关键修正：不能把所有图都推迟到教案文字定稿之后。** 若学生必须从图上读取坐标、比较形状或构造几何对象，图就是题目的一部分，应在关键任务阶段尽早生成并试做。可以延后精修字体、留白和导出尺寸；不能延后会决定题目是否成立的数学关系与可读性检查。这个顺序与已有 [课程到课时执行链](execution-structure-design.md#课程到课时的具体执行链路) 一致。

形式建议也允许被后续证据推翻。若一张图无法在纸笔条件下支持目标，可回到用途说明，考虑换表征或改任务；不能只不断润色错误选择。

## 以当前雪深函数图说明实际工作

以下使用实验已有任务解释候选机制，不修改冻结产物，也不作为新的原创生成输入。

早期用途说明可以是：

> 用一张雪深随时间变化的坐标图，让八年级学生读取初始值和两个点的坐标，求变化率并建立线性函数。建议用黑白静态图；学生版给轴、单位和必要刻度，点只标名称，方程与坐标解答留在教师材料。

生成时，模型需要把这段用途变成明确且可检查的内容。例如当前题的作者侧关系是 `S=2.5t+6`，包含 P1=(4,16)、P2=(8,26)。绘制时由数学关系和坐标变换得到点、线的位置，轴刻度与单位也来自同一份描述；避免让模型各自猜点、线和刻度的像素位置。模型仍负责选择有教学理由的数值、视窗和显示信息，并试做实际学生题面。

随后可以直接提出自然语言修改：

- “把字放大，移开重叠标注，保持数值与题目不变。”重点重查布局，并核对实际差异没有改变数学内容。
- “纵轴改成每格 2 英寸。”需要重查网格、点线位置和学生读数任务，而非只换刻度文字。
- “增加教师讲解用的变化量辅助线。”生成教师用途的版本，学生版保持原定信息；如教师要求学生也看辅助线，重新判断其支持是否提前完成了待考查工作。

教师可以在课时内选中图并描述修改，无需先填写方程参数或理解绘图库。调用方把实际选中版本及教学请求交给 Harness；模型解释要求，模块产生新候选和差异。沿现有授权处理修复；只有超出授权的实质教学取舍或已有流程明确要求审阅时，才等待真实回应。

## Context、生成源和检查各自负责什么

对一张已有图的修订，起始 Context 建议包含：实际题面、当前教学目的及相关目标、原数学描述／绘制源、当前图、反馈证据、受众和学校条件、允许修改范围。必要时回取相邻任务与上层约束。只改标签位置通常不需要重新装入全年标准和全部教案，但不能丢失“学生要自己求斜率”这类决定可见信息的关键条件。

建议保留三类内容，具体文件和字段留待接口设计：

1. **用途与数学内容。** 图服务什么工作；哪些数据、关系和选择已经确定，哪些仍是候选；关联实际任务版本。
2. **可编辑生成源。** 对精确函数图，优先试验由明确数学描述及可复现绘制代码生成矢量图；具体工具尚未选型。初期不建设覆盖所有图类的通用绘图语言。几何构造、定性曲线和情境插图的内容与验证分别处理，不强行套用函数图参数。
3. **实际产物与证据。** 生成图、当前受众／载体的预览、源版本和检查记录。旧版保留，后续改的是明确版本；教师版和学生版共用数学依据，但分别生成实际可见内容。

函数图中的精确位置适合由计算与绘制程序落实；LLM 承担用途理解、表征设计、数值与范围选择、内容生成、试做和修订判断。一般情境插画将来可评估图像生成模型，动画或交互也须有真实教学需求才展开，本轮不一次性建立所有非文字媒体能力。

检查至少关注以下相互不能替代的事实：

| 对象 | 要验证的内容 |
| --- | --- |
| 数学与绘制对应 | 数据、函数、单位、定义域、刻度和点线位置一致；定性示意图则按它实际表达的关系检查，不伪装成精确测量图 |
| 学生承担的工作 | 图、图例、标题及替代描述是否给了本应由学生求出的结果；提示是否符合该任务用途；师生信息分别检查 |
| 实际呈现 | 在目标尺寸和实际页面中检查重叠、裁切、字体、黑白辨识与可作答空间；图单独看得清不保证缩入材料后仍可读 |
| 课时与修订关系 | 数值、关系或支持改变后同步题面、答案和教师引导；检查记录关联实际对象。只改布局不自动要求整门课程重审 |

检查结果应附可核实证据并允许模型反驳误报。替代描述需要按同一教学目的设计，不能为了无障碍说明直接附上教师答案；若更换表征会改变所评技能，须明确说明并处理适配目的，不能宣称完全等价。

## 后续需要采用时怎样验证

从当前实验已有函数图和真实反馈出发，检验一个可复现的绘制与修订模块是否解决问题：先修标注重叠，再做一次刻度调整或教师辅助线版本，核对实际图、题面和答案的一致性。这样能与目前直接生成 SVG 的方式比较，检查精确位置、局部修改、输入消耗及受众信息是否改善。

本次只提出候选，未运行新比较，不能据模块划分合理就宣布效果更好。验证不更改原始评价约定、不抹掉旧失败，也不读取对应 IM 内容。后续若收益只来自一个小绘图工具，就保留那个小工具；只有职责和使用需要支持时才扩大模块。原 Skills 的同源材料、受众区分、实际交付与修订目的继续保留。
