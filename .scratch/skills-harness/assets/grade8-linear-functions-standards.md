# 八年级线性函数：官方标准与候选验证边界

核查日期：2026-09-15。仅使用 CCSS 官方标准；未查阅 IM 网站、课程结构、单元或课时资料。本笔记服务设计讨论，不是课程草案或已接受需求。

## 标准事实

以下“要求”指采用 CCSS 框架时的年级目标，不代表所有美国学校当前统一采用。

- **标准不规定课程顺序。** 标准排列不决定先教什么；不同领域可有关联。标准也未完整规定所有学习路径，不能由编号推出单元位置。[标准阅读说明](https://www.thecorestandards.org/Math/Content/introduction/how-to-read-the-grade-level-standards/)
- **8.F.1–2：函数及表征。** 每个输入恰有一个输出；图像由输入与对应输出的有序对组成；比较以代数式、图、表或文字不同方式表示的函数。脚注明确八年级不要求函数记号。[8.F](https://www.thecorestandards.org/Math/Content/8/F/)
- **8.F.3：线性与非线性。** 将 `y = mx + b` 解释为图像是直线的线性函数，并举出非线性函数的例子；范围不止代入计算。[8.F](https://www.thecorestandards.org/Math/Content/8/F/)
- **8.F.4–5：建模与定性理解。** 构建线性关系模型；从描述或两个点（含图表）确定变化率、初始值，并在情境和图表中解释。由图描述增减、线性或非线性，并按文字特征画示意图。[8.F](https://www.thecorestandards.org/Math/Content/8/F/)
- **8.EE.5–6：同年级联系。** 比例关系作图、单位率与斜率、跨表征比较；用相似三角形解释非竖直直线斜率恒定，推导 `y = mx` 和 `y = mx + b`。[8.EE](https://www.thecorestandards.org/Math/Content/8/EE/)
- **8.EE.7：一元一次方程。** 通过等价变形区分一解、无解和无穷多解；解含有理数系数、分配律及合并同类项的方程。[8.EE](https://www.thecorestandards.org/Math/Content/8/EE/)
- **8.EE.8：二元一次方程组。** 解对应两图交点；代数求解、作图估解、观察简单情形，并解决实际与数学问题。这是独立列出的年级目标。[8.EE](https://www.thecorestandards.org/Math/Content/8/EE/)
- **此前的年级要求。** 6.EE.9 涉及自变量、因变量及方程和图表的联系；7.RP.1–2 涉及单位率与比例关系；7.EE.1、4a 涉及有理系数表达式和指定形式的一元方程。[6.EE](https://www.thecorestandards.org/Math/Content/6/EE/)、[7.RP](https://www.thecorestandards.org/Math/Content/7/RP/)、[7.EE](https://www.thecorestandards.org/Math/Content/7/EE/)

## 候选边界（设计推断）

可用 **8.F.1–5** 作为函数主题的验证核心，明确衔接 **8.EE.5–6**；它们是同年级目标，不能默认已经掌握。**8.EE.7–8** 可列相邻目标，不自动全部纳入本次单元；此前标准可作前置检查依据，不能证明实际学习者已掌握。具体纳入范围、顺序、课时数及“Unit 4”标签均需另行确定。此处没有教学效果证据。
